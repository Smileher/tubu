运行前核对

  • 当前料号与产品一致，膜卷号正确，全部配置相机已经连接。
  • 相机图像方向、亮度和测量区域正确；更换相机或调整位置后，先核对标定、抓边和模板。
  • 需要保存的数据与图像已经开启，保存磁盘有可用空间；需要输出的 PLC、MES 和纠偏设备连接正常。
  • 参数页修改已经保存，布局编辑已经结束；不能仅凭输入框里显示新值判断运行参数已更新。

首次建立料号时，先完成料号配置、标定标零和离线试检，再进入正式检测。

登录后操作

通过主界面用户入口登录，再执行需要权限的操作。账号密码、刷卡、角色权限与会话设置见用户与权限。

开始检测

  1. 打开“涂布CCD软件”，等待初始化结束，核对当前料号、膜卷号和设备连接状态。
  2. 需要权限时，点击用户入口登录。确认当前页面已退出布局编辑等不允许运行的状态。
  3. 返回系统主页，点击绿色“运行”，按软件提示完成配置、图像或模型检查。等待启停进度结束后，再确认运行状态和相机图像。
  4. 运行时观察实时图像、尺寸结果、瑕疵统计和报警；发现异常先查看提示内容，不连续重复点击运行按钮。

启动检查会受当前功能开关影响。启用 AI 分类时，模型未就绪会阻止启动；相机未标定或标定数据无效时也不能开检。运行中出现图像尺寸异常时，按实际提示检查采集、拼图与检测区域。按提示解决原因后重新运行。

运行中观察什么

顶部核对料号与膜卷号；相机画面确认图像持续更新；尺寸表查看测量值和判定；瑕疵列表、局部图与分布图用来定位瑕疵。数据异常时，先确认对应相机、面别和数据集，不混用不同工位的数据。

报警窗口说明异常类型，运行日志说明发生阶段。解除提示并不等于排除了设备故障。人工报警复位的范围见报警复位，它不会替代重新启动检测。

停止与退出

再次点击顶部左侧红色“停止”按钮，等待相机、采集和相关模块完成停止。等待遮罩表示操作尚未结束，不代表程序已经无响应。

正常关闭软件时，若当前参数页有未保存修改，可以选择保存并退出、不保存并退出或继续编辑。保存失败会保留页面，先处理提示再退出。

关闭时的等待与重试

先停止检测，再正常关闭窗口。关闭进度会显示当前相机停流、释放及后台收尾阶段，等待当前动作完成。若提示某些相机释放失败，按弹窗选择重试；只有明确选择强制退出时才跳过失败设备的正常释放。

关闭进度长期停在同一步时，记录完整阶段文字与故障时间并收集日志。不要通过反复启动另一份程序解决尚未结束的设备占用。

若提示“软件收尾中断，已停止运行”，本轮后台任务已收到停止通知，不能继续检测。可再次正常关闭软件重试；详细原因见当天 Error 日志。

运行按钮或界面异常

  • 按钮不可用：停止状态下，非主页会锁定全部快速操作，先返回系统主页；运行中的红色“停止”在各页面保留操作入口，原有登录检查仍生效。若仍有锁定标识，再核对初始化、权限和已有提示；启停处理中应等待结束，不通过强制启用按钮恢复运行。
  • 等待遮罩未结束：查看启停日志中最后一个开始但未返回的阶段，结合相机和控制器日志分析。
  • 状态正常但没有新图：检查相机是否自动停流、设备是否运动，以及相机采集和触发信号。参见相机自动取流。

保留故障时间、当时操作和当天日志。日志位置与收集方式见日志与诊断。

遇到开检提示怎样处理

提示或现象 检查与下一步
“当前为布局编辑模式，无法启动，请先关闭！” 结束布局编辑，回到正常工作状态后再运行，不必重建料号。
“请先登录本系统账号！” 完成账号登录，再执行需要权限的操作。
“本机未配置相机”或“相机未标定,禁止启动！” 核对本机全部配置相机，完成配置并重启，核对对应有效标定后再启动。
“无法启动检测：瑕疵分类AI模型未初始化。” 核对配套模型文件与启动错误日志；确实不使用 AI 时才按工艺关闭相应功能。

出现“系统启动成功！”后，再观察图像和结果是否持续更新；“系统停止成功！”表示本次停止流程已返回。等待进度中重复点击不会并行执行第二次启停。

打开软件与加载提示

打开软件后先显示加载进度窗，初始化期间不显示主窗口。相机、PLC、系统控制器、AI、MES、喷码和本地数据按依赖关系并行准备，部分首页组件同时准备。进度窗第一行显示“正在读取配置”“正在准备运行环境”“正在初始化设备与模型”或“正在准备主界面”；第二行最多显示两个简短模块名，其余用“等 N 项”说明。只剩一个模块且加载超过 3 秒时，显示该模块已用时间，不显示具体配置文件名。

百分比表示启动阶段，不是剩余时间估算；等待设备或模型时可能暂时不变。主界面实际完成首次绘制后才显示 100%，随后关闭进度窗，再处理登录及加载提示。进度条不能代替设备状态或开检校验，加载失败或等待超时仍按原有规则进入主界面并提示。

核心系统配置或料号文件读取失败时，先按提示查看有效备份。可以恢复当前候选、查看下一候选，或取消该模块加载；没有采用备份时，再单独确认是否使用该模块的默认参数。确认恢复或默认参数后会保留损坏原件，再尝试保存。保存失败会记录并提示，仍保留本次确认的内存参数；拒绝默认参数不会关闭软件，依赖该配置的功能暂不可用。恢复或使用默认配置后，必须核对参数并手动启动检测。

单项失败或超时不代表整套软件不能打开。相机或其他设备正常返回连接失败、连接超时时，只记录日志并在底部保持红色状态，不因此弹出启动提示。配置读取、插件或模型加载失败以及程序异常，会在进入主界面后合并为一份“启动加载提示”；按模块检查当天 Error 日志。账号配置无法可靠读取时不进行默认账号自动登录，也不能开检；模型缺失不会被视为加载成功。

启动结束后，操作提示显示最终初始化结果。若提示“账号数据未可靠加载，请查看启动加载提示及日志”，侧栏页面切换和开检暂不可用；先查看“启动加载提示”及当天 Error 日志中的账号数据失败原因，处理后重新打开软件。

底栏状态与错误提示

底栏按运行状态、相机通信、其他设备通信和系统资源分组，未启用的设备不占位置。正常与异常沿用绿色和红色文字及状态灯；未验证或检查中的设备状态以灰色显示。系统控制器按所选类型显示“正运动”“CMR1000”或“CCD PLC”，其他常用名称简写为“主PLC”“纠偏”“喷码”和“多工位”。名称过长时显示省略号，鼠标悬停可查看完整名称或型号。

底栏保持单行，不显示滚动条。设备较多或窗口较窄时，在设备与资源区域使用鼠标滚轮横向查看，运行状态和右侧信息保持固定。启动画面与主页右下角使用同一英文版本标识 tb_年月日_时分秒_现场缩写，日期与时间来自软件构建时间；现场为 default 时省略现场部分。悬停可查看完整版本标识。

右侧“错误”数字是本次错误日志计数，有记录时显示。双击打开当天错误日志目录，右键可“清空”计数或“本次隐藏”；这些操作不删除日志文件。

一次检测的确认顺序

  1. 核对产品、料号、膜卷号与相机，不在错误料号上继续调参。
  2. 确认原图、标定、抓边、检测区域和模板；用正常样与已知瑕疵样检查结果。
  3. 保存修改，检查所需数据、图像及通信输出已配置。
  4. 开始运行，先观察图像，再观察测量与判定，最后核对保存文件及需要的外部输出。

没有图像先查采集；有图但结果不对先查测量或瑕疵，避免同时调整多个环节后失去比较基准。

日志与异常检查

启停过程在日志中搜索 SystemOperation，按同一轮操作找到最后开始但未完成的阶段；自动停流另查 CameraAutoCapture。保留等待界面显示的阶段文字，不仅记录“卡住”。

资料收集方法见日志与诊断。
