选择与管理虚拟图

通过“功能 → 预设虚拟图”或“系统设置 → 预设虚拟图”进入。先确认当前图名称，再编辑；可以保存、另存为、删除、打开其他文件及导入导出。

内置图不能直接覆盖保存或删除，需要“另存为”自定义图。编辑前保留可用版本，完成后再核对料号中选择的虚拟图。

添加控件并绑定数据

  1. 设置画布逻辑宽度与高度，确定整体布局比例。
  2. 添加普通控件或数据控件，调整位置、大小、文字、字体、颜色及背景。
  3. 对数据控件选择数据集和数据源，核对它代表的尺寸、面别和对象。
  4. 按需要配置动态显示颜色，检查正常、异常及无有效数据时的显示。
  5. 保存图形，返回主页检查真实检测数据与布局模块。

编辑预览用于检查布局，不能作为真实在线检测值。运行时“保持比例”可能留白，“拉伸填充”可能改变外观比例；编辑预览始终按比例显示。

选择、对齐与层级

Ctrl 加单击可多选或取消选择。对齐作用于全部选中控件；复制、删除和属性编辑作用于当前控件。执行前观察当前选中状态。

“上移”“下移”调整控件遮挡层级，不是移动坐标。画布尺寸变更会影响整体控件布局，改动后逐项检查位置和文字是否被遮挡。

预设尺寸名称

“系统设置 → 预设尺寸名称”维护后续选择时的候选名称。预设 Code 不能修改或删除，可调整显示名称；自定义项目可以新增。Code 与 Name 都不能为空或重复。

取消下拉显示只影响候选，不会删除已有料号中的尺寸。修改名称候选也不会自动改写旧料号；需要修改正在使用的测量项目时，进入对应料号参数页保存。

虚拟图没有数据或显示不对

依次确认当前料号使用的虚拟图、主页布局中的模块、控件数据集和数据源，以及检测是否产生有效结果。先区分没有数据、绑定错误和控件被遮挡，再调整配置。

从预设图制作一张可用示意图

  1. 打开接近当前工艺的预设图，先另存为自定义名称。
  2. 调整画布比例、材料示意块与文字，让 A/B 面和干湿工位关系清楚。
  3. 逐个添加或选择数据控件，绑定实际数据集和测量项目；先检查一项真实数据，再复制布局。
  4. 调整层级与对齐，检查字号和正常／异常颜色；保存。
  5. 在当前料号选择该虚拟图，并核对主页布局中的显示模块，再运行观察。

示意图只负责展示。控件上写“宽度1”不代表已绑定宽度1；需要检查实际数据源。尺寸改名或工位反转后，重新核对绑定和显示含义，参见名称与 Code 反转。
