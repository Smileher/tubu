特征分类

关闭 AI 分类时，在“特征分类”列表配置缺陷名称与特征条件。“命中顺序”按当前列表自动编号，用“上移”“下移”调整：从上到下检查启用规则，第一条命中即停止。多条规则同时满足时，仅采用最前面一条的类别。具体规则应放在前面，宽泛规则放在后面。

新增规则默认停用；填写名称、设置条件并核对顺序后再勾选启用。启用名称不能为空或仅含空白，名称不能包含非法字符。同一规则内已启用的条件须全部满足，上下界均包含等号；0 是真实边界，不表示不限。不限制某个特征时取消该特征的启用勾选。未启用任何特征条件的规则会无条件匹配，应放在列表最后。

面积单位为 mm²，宽度和长度分别为横向、纵向外接范围，单位为 mm；平均灰度取候选区域在检测图中的平均值。横坐标、纵坐标是缺陷重心在半尺寸工作图中的像素坐标，按原图坐标除以 2 填写。半径按横纵平均分辨率近似换算；“偏心率”特征实际为等效椭圆主、次半径之比，无单位，不是 0～1 的几何偏心率。圆度、矩形度和等效椭圆轴比按工作图的像素形状计算，横纵分辨率不同时，不等同于物理坐标中的形状。

特征范围按实际测量值判断，包含上下界，并吸收特征换算产生的微小浮点舍入误差；不会按界面显示的小数位取整后判断。

规则未命中时按“未知”处理，仅当面积达到“未知缺陷最小检出”时保留；这个下限不用于已经命中类别的候选。小于下限的未知候选会在二次分类前剔除，无法通过二次分类找回。特征分类按尺寸修正前的测量特征匹配；二次分类使用尺寸修正后的结果，还可能改变最终名称。名称为 OK（不区分大小写）的结果会被剔除，不作为正式缺陷输出。

使用页面底部“整图检测”检查最终结果。先用已知缺陷图核对类别与位置，再用正常图检查误报。调整顺序、条件和启用状态后需统一“保存”，正式检测才使用新配置。

二次分类规则

二次分类仅处理已经保留的检测结果。规则按列表顺序执行，第一条匹配后改名并停止；未匹配则保留原名，不连续改名。上移、下移决定优先级。二次分类本身不直接剔除结果；改名为 OK 后，由最终 OK 过滤剔除。

分类名称匹配、按类别修正尺寸、AI 标签映射及类别边缘屏蔽均忽略首尾空白和大小写，保留名称中间空格。例如 ok 与 OK 均会忽略，O K 不会当作 OK。最终 OK 自动忽略，没有独立启用开关。AI 标签忽略首尾空白和大小写后重名时，检测提示配置歧义，不任意选取一条映射。

条件可使用长度、宽度、面积、长度/宽度、宽度/长度和灰度等已提供特征，支持比较、且、或和括号。且可写为“且”“与”或 &&，或可写为“或”或 ||。例如 宽度 >= 1 且 面积 >= 2、长度/宽度 >= 0.3。这里的 0 是真实零值；不限制某个量时应省略该条件。

改名不重新计算测量值，原分类编码和 PLC 地址等字段保留。被最终过滤的候选不能通过二次分类找回。

底涂过滤

“过滤底涂 → 识别区域”可选择当前相机的命名区域，留空使用全图。判定只统计选区与图像交集中的像素；判为底涂后清空该相机当前结果、跳过后续检测并参与同步。修改后需保存料号。

先分清正在调整哪一层

候选提取负责找到可能的缺陷；AI 或规则给出类别；结果筛选决定候选是否保留；二次分类对保留结果改名。某项过滤已经剔除的候选，不会因为新增二次分类规则重新出现。

“特征分类”和“二次分类”的条件含义不同。特征分类中同一规则内启用条件共同限制命中；二次分类按列表顺序首次命中即停止。需要排查最终名称时，分别检查原类别、筛选结果和改名规则。

编辑二次分类条件

  1. 在瑕疵工具打开“二次分类”，新增规则并填写来源、目标名称和条件。
  2. 通过条件编辑器插入长度、宽度、面积、长宽比或灰度属性及比较符，使用括号、且/与/&&、或/||组合。
  3. 点击“验证”确认表达式有效，再确定并调整规则顺序。
  4. “应用到草稿”后先做离线测试，再回到主参数页点击“保存全部参数”。

长度与宽度单位为 mm，面积为 mm²，长宽比无单位，灰度为 0～255。长度/宽度或宽度/长度的分母为 0 或无效值时条件不命中。条件中的 0 是真实数值；不限制某项时省略该比较，不填写其他算术、函数或不支持的字段。

过滤过多或误报时

先核对图像和区域，再检查长宽面积的单位及上下界。AI 结果筛选的三项范围须同时满足；过滤兜底只检查已提取且范围未达标的候选，不会找回更早已被剔除的区域。

边缘过滤和底涂过滤还需检查识别区域、内缩及灰度条件。选区位置不正确时，应修正区域，不通过反复改类别名称处理。

过滤结果显示范围

参数页整图试检对已形成的碳膜候选显示过滤来源、原因、区域及测量值：包括噪点面积筛选、候选数量限制、AI 原始 OK、AI 尺寸筛选及兜底、特征分类未知面积不足、AI 边缘屏蔽和最终 OK 忽略。特定瑕疵预检测也显示面积、长度、数量筛选及最终 OK 的诊断。图像保留简短标记，“过滤/保留说明”可查看完整来源、区域、原因及测量值，选中记录可定位。被过滤或忽略的候选统一用绿色文字和框标注，仅供离线检查，不进入正式缺陷列表、统计或 PLC 输出。

保留的未知仍按缺陷用红色标注，并区分未命中特征规则、直接命中名为未知的规则、AI 分类映射为未知、AI 过滤兜底及二次分类改名等来源。二次分类与边缘屏蔽会更新同一候选的诊断，兜底结果若随后被剔除，最终显示绿色。未知来源不改变其最终类别名称。

检测区域之外或灰度阈值提取前未形成候选的位置无法逐项标注。在线只输出最终保留结果，不增加这些离线诊断提示或逐候选过滤日志。检测异常须查看错误提示和 Error 日志，不能当作正常过滤。
