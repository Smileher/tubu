二次分类规则

二次分类仅处理已经保留的检测结果。规则按列表顺序执行，第一条匹配后改名并停止；未匹配则保留原名，不连续改名。上移、下移决定优先级。

条件可使用长度、宽度、面积、长度/宽度、宽度/长度和灰度等已提供特征，支持比较、且、或和括号。且可写为“且”“与”或 &&，或可写为“或”或 ||。例如 宽度 >= 1 且 面积 >= 2、长度/宽度 >= 0.3。这里的 0 是真实零值；不限制某个量时应省略该条件。

改名不重新计算测量值，原分类编码和 PLC 地址等字段保留。被最终过滤的候选不能通过二次分类找回。

底涂过滤

“过滤底涂 → 识别区域”可选择当前相机的命名区域，留空使用全图。判定只统计选区与图像交集中的像素；判为底涂后清空该相机当前结果、跳过后续检测并参与同步。修改后需保存料号。

先分清正在调整哪一层

候选提取负责找到可能的缺陷；AI 或规则给出类别；结果筛选决定候选是否保留；二次分类对保留结果改名。某项过滤已经剔除的候选，不会因为新增二次分类规则重新出现。

“规则分类”和“二次分类”的条件含义不同。规则分类中同一规则内启用条件共同限制命中；二次分类按列表顺序首次命中即停止。需要排查最终名称时，分别检查原类别、筛选结果和改名规则。

编辑二次分类条件

  1. 在瑕疵工具打开“二次分类”，新增规则并填写来源、目标名称和条件。
  2. 通过条件编辑器插入长度、宽度、面积、长宽比或灰度属性及比较符，使用括号、且/与/&&、或/||组合。
  3. 点击“验证”确认表达式有效，再确定并调整规则顺序。
  4. “应用到草稿”后先做离线测试，再回到主参数页点击“保存全部参数”。

长度与宽度单位为 mm，面积为 mm²，长宽比无单位，灰度为 0～255。长度/宽度或宽度/长度的分母为 0 或无效值时条件不命中。条件中的 0 是真实数值；不限制某项时省略该比较，不填写其他算术、函数或不支持的字段。

过滤过多或误报时

先核对图像和区域，再检查长宽面积的单位及上下界。AI 结果筛选的三项范围须同时满足；过滤兜底只检查已提取且范围未达标的候选，不会找回更早已被剔除的区域。

边缘过滤和底涂过滤还需检查识别区域、内缩及灰度条件。选区位置不正确时，应修正区域，不通过反复改类别名称处理。
