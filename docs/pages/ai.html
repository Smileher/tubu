注册瑕疵模板

  1. 准备与当前相机、料号和工艺一致的标准图像，检查参与的碳膜或涂料区域。
  2. 点击“注册”，软件重新定位启用区域；没有图像、区域无效、越界或必要边缘失败时不能注册。
  3. 确认窗口中核对当前相机、区域数量、名称、平均灰度和标准差。发现异常先返回检查，不把警告当成普通成功提示。
  4. 确认后先生成待保存候选，注册图时间显示“待保存”。可先试检，再点击统一“保存”正式生效。

试检优先使用当前页面候选，正式在线检测继续使用已保存模板。放弃页面修改不会替换正式模板。质量提示不能识别所有整体一致但选错位置的图像，仍需核对实际取图内容。

AI 模型与结果筛选

导入模型前先停止检测。按当前模型类型同时选择 ONNX、配置 JSON 和标签 JSON 三个配套文件；确认窗口会显示新旧文件时间、标签与重载行为。导入成功后新模型立即激活。

标签名称或数量变化时，需要同步标签参数。选择暂不同步会保留原表和差异提示，但不会回退新模型；完成同步后核对各类参数并保存料号。启用碳膜 AI 时，标签未同步会阻止开检。

“AI结果筛选”的长度、宽度和面积采用且关系，全部启用边界均满足才保留原分类；某一侧为 0 表示该侧不限，等于边界可以通过。

启用“过滤兜底”后，不符合长宽面积范围的候选，会在当前候选区域内分别统计亮、暗有效像素面积。任一侧达到有效面积下限时，以“未知”保留；两侧面积不相加。

参数页整图“检测”中的绿色框表示被过滤候选，只用于参数检查，不进入正式 NG、统计、PLC 或二次分类。“小图分类测试”只验证当前分类器输出，不经过业务筛选，不能用整张小图尺寸代替瑕疵测量值。

注册前的准备

先确认当前相机和料号，使用清晰、正常且无缺陷的图像，检查定位边缘及启用区域。标准图用于建立背景参考，不能用缺陷样本或错误相机图像代替。

注册确认中的区域名称、数量、均值和标准差用于检查本次图像是否合理。“待保存”表示当前候选尚未正式提交，不能据此认为在线检测已替换标准图。

重载与小图分类测试

“重载模型与标签”用于重新加载当前模型及标签映射。完成后检查模型状态、标签差异和当前料号参数；模型加载失败时保留提示和当天错误日志。

“小图分类测试”选择一张灰度瑕疵小图，只显示模型分类结果，不执行面积筛选、过滤兜底或二次分类。检查完整业务结果时，使用瑕疵工具中的整图检测。

分类与实际缺陷不符

  • 检查模型和配置、标签文件是否配套，导入后标签是否已同步并保存。
  • 检查图像来自正确相机、工艺与区域，尺寸和灰度条件是否与模型使用条件一致。
  • 区分原始模型类别与筛选后、二次分类后的最终名称。
  • 保留原图、局部图、最终结果和模型文件时间。增加样本或重新训练需要另行准备，修改类别名称不能替代模型能力。

注册或换模型后的确认清单

  1. 确认当前相机、料号、工艺及图像属于同一套使用条件，标准图无缺陷。
  2. 注册候选先试检并保存；新模型导入后立即激活，两种操作的生效方式不同。
  3. 模型标签有差异时，完成同步并逐类核对筛选参数，再保存料号。
  4. 用正常原图、已知缺陷原图和边缘样本做整图检测，对照原类别、保留结果及最终类别。
  5. 确认正式配置后再开检，同时保留模型配套文件时间和可复现的原始图像。

模型文件导入成功、标签同步成功与整图检出正确是不同检查项；不能只看一次小图分类成功就结束验证。
