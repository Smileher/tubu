PLC 与系统控制器

软件提供主设备 PLC 和系统控制器两类控制连接，分别检查对应的启用状态、型号、地址和数据类型。软件的尺寸结果、报警、纠偏、清米等输出各有条件，不能只凭“PLC 已连接”认定全部点位都在写入。

“系统设置 → 系统控制器 → 控制器连接”的启用状态保存后需重启生效。未启用时跳过该控制器连接、心跳、周期读取以及对应清米、编码器和采集门控，相关读写测试不可用；独立主 PLC 的原有业务不受此开关代替。

“调用结束”“写入已调度”“写入成功”和“设备实际动作完成”不是同一结果。排查时应逐层核对软件返回、PLC 点位和设备动作。

主设备 PLC 连接与测试

进入“数据交互 → 主设备PLC”。顶部一行设置启用、协议、IP 和端口；Modbus RTU 改为填写 COM 串口和波特率。下方依次为“尺寸输出”“瑕疵输出”“通用点位”，共用此主设备连接。

停止检测后点击“连接”，先保存当前通信参数，再重连主设备 PLC；保存失败保留原连接。该按钮不保存尺寸或瑕疵表格，也不重连系统控制器。表格和通用点位仍通过页面底部“保存”维护。连接和点位测试进行期间不能启动检测。

“辅助参数”按协议显示：西门子 Rack／Slot 默认 0，旧“IP:槽位”配置仍兼容；FINS 的 SA1 为本机节点、DA1 为 PLC 节点、DA2 为单元号，节点留空沿用原自动或协议默认值，UDP 的 SA1 默认 192；Modbus 站号默认 1，TCP 字节序默认 CDAB、RTU 默认 ABCD，默认地址从 0 开始；串口默认 8 数据位、无校验、1 停止位。应与设备侧设置一致。原有配置未填写新增参数时沿用历史默认值。

填写“测试点位”，选择 bool、int32 或 float 后点击“测试读取”；测试发送还需填写“写入值”。bool 接受 0、1、true、false。所有测试均按原始值直接读写，int32 为 32 位整数，不采用尺寸输出的乘 100 规则。发送会改变真实 PLC 点位，请确认目标地址和数值后操作。失败显示本次应答原因，不将默认 0 或 false 显示为成功。

测试使用当前正式主设备连接；修改通信参数后需重新点击“连接”。UDP 的目标可达仅表示网络检查通过，需通过点位读取确认 FINS 应答。正常退出和 Windows 正常关机时先停止 PLC 后台任务再释放连接；突然断电或强制结束进程无法保证发送断开报文，PLC 侧可能需要等待连接超时。

主设备 PLC 点位

在“数据交互 → 主设备PLC → 通用点位”，按生产信息读取、实时数据与控制输入、心跳与通信、软件与检测状态、闭环及专用业务信号分类设置；每项旁边说明读写方向、触发时机和格式。尺寸和瑕疵事件报警在“报警设置”中独立配置。

测量值与分类瑕疵分别在“尺寸输出”和“瑕疵输出”页签维护独立配置。控制器断连状态量继续同步“故障 1、正常 0”，与详细报警的断连事件地址独立，不使用报警保持时间。数据更新完成和点检超时停机等业务点位继续保留。

规格牌和详细报警的事件输出支持“地址|bool”“地址|int”“地址|float”，省略类型按 float 写入；人工复位命令在详细报警公共设置中单独选择类型。保持和复位行为参见PLC 报警保持时间。

无锡松下刻码

无锡松下现场使用专用刻码信号。启用双面检测并配置 AB 面相差笔数后，软件按相差方向配对两面的瑕疵和刻码尺寸：正数表示 A 面先到，负数表示 B 面先到。前面的未配对笔数会等待对应另一面到齐，配对完成后只发送一条刻码信息。

多同步组场景会等待完整批次再发送，避免同一物料由局部结果重复触发。在“数据交互 → 主设备PLC → 通用点位”设置刻码内容地址和“无锡松下刻码NG通知地址”；通知地址仅在无锡松下现场配置中显示。刻码内容写入成功后，软件向专用通知地址写入整数 0；内容写入失败时不发通知。地址缺失或通知写入失败时，按通信日志处理，不能只凭内容已写入认定整次发送成功。

通用 NG 功能类型 M/D 输出及其配置已移除。无锡松下专用通知使用独立地址，升级后必须重新配置，不继承旧检测功能地址。正常检测结果、尺寸／瑕疵输出及其他业务点位继续按各自规则工作。

修改料号、换卷、停止检测或调整 AB 相差笔数后，应重新确认配对状态从新批次开始。出现等待超时、帧序列中断或 PLC 写入失败时，结合通信日志检查当前批次是否被丢弃以及地址配置是否正确。

MES 通信

通用 MES 使用一份主配置，支持 TCP、HTTP、MQTT，分别配置尺寸过程上传和瑕疵过程上传。尺寸包含现有尺寸与错位数据。料号切换不再选择其它 MES 配置；冠宇认证、换型和生产开停、达力卷号和文件通知等专用业务继续使用对应项目流程。

  1. 打开“MES 配置”，核对“启用 MES”、协议和连接参数。HTTP 在选中接口后填写对应的完整 URL；TCP、MQTT 填写主机名或 IP 和 1～65535 的端口。
  2. 选择“尺寸过程上传”或“瑕疵过程上传”，勾选对应的“启用尺寸上传”或“启用瑕疵上传”。新建配置默认使用模板替换，也可切换为固定格式；两种模式分别保留编辑内容，已有配置按保存的模式打开。
  3. 配置参数来源，点击右侧“检查配置”，再用“测试发送”检查返回结果。运行中可以编辑、检查和测试；停止检测且待上传任务处理结束后，点击“保存并应用”。保存继续按现有权限确认。

应用成功后更新生产连接。保存成功不代表服务器可达；断连时检查目标及返回原因。MES 总开关与主配置开关同步；启动时发现不一致，按关闭优先处理并记录日志。

协议设置与核对
HTTP填写 http:// 或 https:// 开头的完整地址。正文方式包括“JSON（UTF-8 无 BOM）”“表单字段”和“JSON（UTF-8 带 BOM）”，新配置默认无 BOM。表单方式需填写承载正文的字段名；带 BOM 方式的正文开头包含 UTF-8 字节序标记，按接收方要求选择。HTTP 不要求 Ping 成功，以实际请求结果判断。
TCP普通正文用 UTF-8；“专用报文封装”用 GB2312，格式为 STX + 消息序号 + TAB + 设备名称 + TAB + 命令标识 + TAB + 正文 + ETX。STX 为 0x02，TAB 为 0x09，ETX 为 0x03；勾选封装后才显示设备名称及当前接口的命令，尺寸与瑕疵命令分别设置。
MQTT填写客户端标识、认证信息和发布主题；发布主题不能含 + 或 # 通配符。仅发布上传报文，不配置订阅。旧配置需要的网关连接通知按原行为保留。

MES 模板与固定格式

模板模式从左到右为变量绑定、报文模板和发送测试，区域间距固定。左侧绑定表纵向滚动，选中行后先选“数据范围”，再选过滤后的“具体数据”。范围分为运行参数、检测结果、单个瑕疵、各尺寸与错位数据集、其它来源；选择“固定值”时直接填写内容，不显示具体数据。尺寸与错位显示实际名称及属性；本机候选取当前料号启用项，交互候选包含对应数据集的可见预设名称及已收数据，不需要在本机料号中新增测量项。主动切换范围后，原来源不适用则清空并等待重新选择，不自动改绑；读取已有配置时保留候选之外的原绑定。固定格式的选中项设置位于字段表右侧，字段名可编辑，嵌套子字段采用相同选法。连接设置中的 TCP 封装、MQTT 等参数使用右侧空间排列，窗口较窄时自动换行。

同一报文可以混合绑定尺寸、错位、瑕疵及运行参数。本机测量取本笔结果，交互测量取上传处理时的最新缓存，不按米数或采集时间严格对位；交互接收本身不触发 MES 上传。尚未收到的交互字段按缺省值规则处理，已有非空缓存不会因通信中断自动变成缺省值。“单个瑕疵”指瑕疵报文当前处理的那一项，不代表选择相机或其它设备；尺寸报文可以绑定本笔瑕疵数量、类型列表等参数，但不提供单个瑕疵明细。“本笔本机尺寸/错位判定”不包含交互尺寸的整体合并判定。

尺寸与错位的“测量值”为原始测量值加默认补偿；“现补偿值”对应尺寸配置中的现补偿参数，原“补偿值／错位值”和“第二补偿值”来源均按现补偿取值。“结果值”读取检测完成后的实际最终结果，保留表达式、标准片缩放等处理结果，不在 MES 中重新计算。

点击“添加”生成“变量1、变量2……”等固定标识，选择来源后点击该行的“复制”，再在模板需要的位置粘贴蓝色的 #变量1#。复制只写入剪贴板，不改动正文或光标，也不会拆开已有变量；粘贴位置由操作者确定，可用撤销恢复。已有配置的自定义变量名称保留，模板绑定标识只读，避免改名后与正文脱节。也可直接在正文输入占位符，软件自动列出待绑定项。“正文”列显示出现次数、未绑定或未插入；未插入的配置行不会参与发送。同一变量可重复出现并使用同一测试值，但不能配置冲突的同名绑定。

已有客户 JSON 时，可直接粘贴原始正文，点击“从 JSON 生成变量”：按正文顺序将每个叶子值替换为独立的 #变量1#、#变量2# 等，并重建当前接口左侧绑定。支持嵌套对象、数组及根数组，保留字段名、数组顺序和空容器；原字符串值保留双引号，数值、布尔值和 null 的占位符不加引号，相同原值也分别编号。字符串内部的 JSON 不再拆解。已有绑定或测试值时先确认清空，取消则保持原状；非 JSON、没有可替换值或已含占位符的正文会被拒绝。

简易步骤：①粘贴 JSON 并生成变量；②左侧逐项选择来源或“固定值”；③检查配置，再测试发送。生成后仍可手工编辑正文，将某些占位符直接改回常量，例如 "设备":"CCD01" 或 "数量":1；未在正文使用的绑定不参与发送。“格式化 JSON”只调整缩进，不修改绑定和手动测试值，支持撤销；也支持含未加引号占位符的 JSON 模板，语法无效时提示并保留原文。粘贴只接收文本，不带入来源文档的字体和段落样式；粘贴、格式化、生成变量和手工回车使用统一的行间距。编辑区字段名用紫色、变量用蓝色区分。

模板不选择数据类型，只把占位符替换为参数原文，不限制 JSON、XML 或其它报文格式，也不自动加引号或转义。例如 卷号=#roll#;速度=#speed# 可直接使用。引号、分隔符、换行及业务结构由模板自行控制，替换值中的占位符不会再次展开。

选择“固定值”并填写内容后，对应变量直接使用该内容，不再读取系统设备编号等来源；显式固定值也允许空字符串。编辑区、导入内容和手动测试值不会自动替换生产配置，须停止检测并成功“保存并应用”。出现设备编号缺参时，先核对报错的模板变量、该变量的实际来源及保存结果；同一报文中的其它变量仍可能绑定“设备编号”，不能只检查某一个固定值。连接成功不代表本次报文已生成或上传成功。

固定格式可配置普通字段、嵌套数组和嵌套 JSON，选中嵌套字段后编辑下方子字段。普通字段与子字段只选择“字符型”或“数值型”：字符型自动加双引号并转义，数值型必须是有效数字且不加双引号。键值数组沿用 Param_Code、Param_Value 格式。嵌套 JSON 的父字段选择字符型时，整个对象作为 JSON 字符串输出；其它方式按嵌套结构生成对象。

选择数据来源后，下方只显示可选的“缺省值”：来源缺失、为 null 或空字符串时，使用已填写的缺省值；0、false、NG 和仅含空格的字符串均不算空。留空表示不启用兜底；未取到必需参数时仍阻止该条报文。选择“固定值”时直接使用固定内容，允许空字符串，不使用缺省值。旧配置中原有的非空固定覆盖，在编辑副本中明确显示为固定值，保持原发送内容；读取不改写文件。缺省值也需保存并应用后才用于生产。

使用缺省值时，测试状态显示“缺省值”，悬浮可查看原始来源；生产日志记录接口、卷号、字段或变量及原因。未绑定变量、数值类型错误、JSON 结构问题或通信失败不使用缺省值掩盖；被阻止的报文不会自动补传。JSON 在编辑区缩进显示，保存及发送时仅压缩字符串外的排版空白，字符串内部的空格、转义和换行内容保持不变；普通文本、XML 及无效 JSON 原文保留。“检查配置”检查连接参数、绑定、测试值和报文，不发送请求；当前接口未启用时也检查并提示。JSON 格式问题单独提示，不限制普通文本或 XML 模板发送。

时间来源含义与单位
本地时间（yyyy-MM-dd HH:mm:ss）进入 MES 处理时的本地时间，例如 2026-11-03 09:18:00。
UTC 时间（yyyy-MM-ddTHH:mm:ssZ）对应的 UTC 时间，例如 2026-11-03T01:18:00Z。
Unix 时间戳（秒）／Unix 时间戳（毫秒）自 Unix 起点的秒数／毫秒数，作为 JSON 数字使用时不加双引号。

同一份报文重复使用时间变量时取值一致，不要求先打开页面或连接成功。已有检测值取本笔结果；设备编号、料号、卷号、当前速度、当前米数和当前账户在入队时固定。当前时间表示 MES 处理上下文时间，不能当作相机采集时间。账户来源不包含密码。共享文件字段及既有 PLC 地址占位语法继续按现场配置使用，不会因此增加 PLC 读取。

MES 上传频率与瑕疵范围

尺寸接口显示“每 X 笔发送 1 次”，每笔按全部同步组到齐后的完整批次累计，不是时间间隔，X 至少为 1。瑕疵接口只显示“仅发送首个瑕疵”，无瑕疵时不发送瑕疵明细；未勾选时，每个瑕疵分别生成一份报文；勾选后只上传该笔现有列表中的第一个，不排序、不跨笔合并。

首个选项只影响明细上传，不减少参与检测与计数的瑕疵。新配置默认全部上传；旧配置首次加载时推导并显示原有首个或全部规则，保存后明确记录。本次不提供换卷统计上传接口；共享文件结束状态和旧卷排队数据失效规则继续生效。

MES 测试与配置文件

  1. 进入页面或切换接口后自动填充测试数据，无需先点击模拟：按当前料号模拟一笔尺寸、错位和瑕疵；补偿、标准值和上下限保留配置参数，已收到的交互项使用缓存中的参数，只有预设名称且没有参数的交互项按默认参数模拟。模拟结果包含默认补偿和现补偿，不改写生产数据；时间、设备编号、卷号、速度、米数、账户等使用当前真实快照。测试行按模板中变量首次出现的顺序排列，包括固定值；重复变量只显示一行，不同变量即使来源相同也可分别修改。点击测试值即可连续输入，无需双击进入单元格编辑。悬浮查看来源，“状态”列标出自动、固定值、缺省值、手动或缺项。未绑定项需先设置来源；来源缺值时可配置缺省值，或仅为本次测试手动填写。手动测试值不会修复或保存为生产来源。测试值填充后保持固定，更换某项绑定后该项重新填充；收到料号或卷号更新通知后重新填充自动值，其余绑定未变的手动值保留。
  2. 点击“测试发送”，自动填充参数、生成报文，使用独立连接向当前目标发送，MQTT 测试使用临时客户端标识以避免挤掉生产连接；无需先生成预览；结果显示目标、耗时、返回或失败原因。测试会产生真实请求，使用前核对目标服务器及主题。

TCP 写入完成、MQTT 发布完成、HTTP 成功状态和 MES 业务接受是不同结果；通用 TCP 未定义业务应答时只能确认已写入连接。HTTP 显示实际状态码和返回正文，带 BOM 方式也会保留错误返回；返回正文仍需按接收方约定核对。独立测试成功不能代替生产通道验证。

“导入配置”只加载编辑副本，显示兼容转换与校验提示，保存前不改变生产配置。“导出配置”校验并导出当前编辑内容，不应用配置，不能直接覆盖生产主文件。唯一通用主文件仍为 MesConfig.xml；读取不会改写原文件，保存失败保留原文件，成功替换时保留 .bak 备份。

旧 Http_Json 转为 HTTP JSON 正文方式；旧主机和接口路径转换为完整 URL，完整 URL 不重复拼接。已删除的通用接口提示后不执行；UDP、PLC 直传及未识别协议会报错，不自动转成 TCP。导入或迁移失败时保留原文件和当前有效配置，修正错误后再导入。

地址支持“地址|float”或“地址|int”；不写类型时按 float 发送测量值。int 将测量值乘以 100 后四舍五入，接收端需按比例还原。此页不输出标准值、上下限、补偿值、状态、均值或方差。

瑕疵输出

在同一功能下打开“瑕疵输出”，点击“新增瑕疵”，再点击名称单元格，从当前料号瑕疵检测名称下拉框中选择；可用键盘按名称前缀定位。填写 PLC 地址并勾选启用后保存。已有配置中的名称仍保留在下拉候选中，便于查看和维护。名称与检测结果最终显示名称匹配；特征分类和 AI 分类同名时使用同一项配置。瑕疵检测页面只维护检测参数，发送地址在此页维护。

出现匹配瑕疵后，后台向对应地址发送 1。不写类型或使用“地址|bool”时写入 true；“地址|int”写整数 1，“地址|float”写浮点数 1。软件不负责将此类点位清零，不提供确认握手或历史补发。

重复通知可能合并，PLC 繁忙时允许丢弃部分待发送通知；断连期间不保留历史通知，单次失败记录日志后继续。此功能用于瑕疵出现提示，不作为逐个瑕疵的可靠计数。保存配置、切换料号及关闭软件时清除等待请求；已进入驱动的写入可能在其超时前结束。

旧输出配置迁移与保存

升级后首次启动自动逐条迁移全部料号中的尺寸、错位测量地址及规则／AI 分类瑕疵地址：当前料号优先，其次保留已有独立配置，其他料号只补缺项；同一输出地址仅保留高优先级项目。停用项目保留停用状态，有效 AI 地址默认启用。

新配置成功保存后清空对应旧输出地址并记录迁移标识。旧的其他尺寸输出地址也清空，不再发送；迁移完成后在两个独立页签维护，不会再次用旧料号覆盖手动修改。尺寸保存为 AllSizeInteractionConfig.json，瑕疵保存为 DefectInteractionConfig.json。

非法单项保留必要旧地址，保存失败保留对应旧配置并在下次启动重试，旧发送链路不会恢复。启动迁移或读取异常不弹窗，在尺寸、瑕疵交互页显示简要提示；查看 Error 日志中的“PLC交互迁移”核对未迁移项和冲突取舍。两个页签保存时统一检查名称、数据集、地址类型和重复地址；修正提示后再保存，停用项也不能与其他项目占用同一地址。

控制器读写与通信排查

喷码使用独立的 TCP 连接和喷码配置页，设备参数不再从数据交互页或旧 SystemInfo 读取。类型仅支持依玛士 NG16 结果式与多米诺 ASCII 坐标协议；两种机型参数分别维护；区域表自动列出全部相机及区域，可逐行启停。配置、自动迁移和应答排查见独立喷码配置。喷码 IO 使用系统控制器，TCP 测试通过后仍需确认控制器连接及输出点位。

在“系统设置 → 系统控制器”检查型号、IP 或串口，再检查各点位的读写方向。读写测试使用“地址|类型”，类型为 int、bool 或 float，并填写与类型一致的值。

手动写入会影响真实设备点位，测试前应确认设备状态和目标地址。系统控制器未启用时，参数下发和读写测试不可用。

MES 上传失败时，分别核对功能启用、网络连接、接口请求与返回。卷号获取、数据上传、登录或日志上报是不同业务，单个接口成功不能代表其他接口也成功。

连接正常但没有输出

检查顺序需要确认
1. 连接对象主设备 PLC、系统控制器、纠偏设备和 MES 是不同对象，检查实际输出使用的通道。
2. 触发条件报警是否达到计数条件，纠偏是否满足采样与许可，尺寸输出是否有匹配的有效数据。
3. 点位及格式核对地址、读写方向、float／int／bool，以及对应功能的缩放规则；不要将尺寸输出的四舍五入与纠偏的截断混用。
4. 本次返回查看同一时刻的发送结果与错误，不以历史连接成功替代本次写入确认。
5. 接收与设备软件报告写入成功后，继续确认 PLC 中的值、设备许可和接收端处理。

以“尺寸输出”为例，显示 12.345 时，float 输出保留测量数值，int 输出将值乘以 100 后四舍五入。接收端必须按同一比例解释。该示例不能套用到报警布尔信号或其他通信功能。

MES 上传失败保留哪些信息

  • 记录发生时间、接口用途、料号与卷号，区分卷号读取、生产数据上传和文件通知。
  • 保留本次返回码、返回正文及软件错误，不只记录“网络正常”。
  • 核对本地待处理文件是否生成；文件同步和 MES 业务确认属于不同环节。
  • 项目专用接口按该接口要求处理，不能以一个接口成功推断全部业务已完成。
