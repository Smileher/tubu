结果与文件保存

软件启动后自动运行本机历史归档和查询服务，不需要打开或启用工位数据交互。本机检测数据写入 SQLite；过程 CSV、图像和统计 JSON 按各自保存开关输出。启用本机汇总服务时，同一数据库还保存接收到的其他工位数据。数据库只保存检测标量及图像引用，网页不参与检测、报警和实时错位计算。

页面显示结果、任务已入队和文件成功写入属于不同阶段。换卷报表依据旧卷快照输出，后台保存可能晚于主页膜卷号更新，应按旧卷号查找文件。

设置保存类型

在“系统设置 → 文件保存”分别设置过程 CSV 和图像路径。“历史数据库”目录下的 LineHistory.db 保存本机历史；作为主控机时同库保存线体归档。修改数据库目录后重启软件生效。所有日期保存在同一个数据库，通过采集日期、膜卷和工位查询，不按天创建文件夹或数据库；运行期间的 -wal、-shm 文件由 SQLite 管理，不要单独删除或只复制主库作为在线备份。

“报表明细”控制本机 PDF 的瑕疵图像明细缓存，最多保留当前卷最近 10,000 处的纯数据索引，完整计数使用统计 JSON；达到上限时 PDF 会说明明细范围。软件重启后不会恢复该内存明细。

尺寸 NG 大图的“连续上限”限制连续 NG 期间的存图，尺寸与错位综合结果为 OK 时清零。计数达到上限即跳过本次保存，因此实际允许入队数量可能少于设定值。该设置不改变检测结果。

保存路径与文件归属

动态路径按检测上下文生成，检查文件时核对日期、料号、膜卷、相机和面别。需要查看关联图像时，同时开启对应图像保存项；图像自动清理、移动或来源工位离线会导致图片暂不可访问，但已归档检测数据仍可查询。

打开数据看板

  1. 启动软件，本机归档与查询自动运行。单机使用无需启用工位数据交互，也无需填写服务器 IP。
  2. 从顶部“数据 → 数据看板”打开独立网页窗口，入口位于原数据查询菜单项下方。原查询入口也打开此看板。
  3. 页面先显示最近有归档数据的日期和膜卷，随后加载统计图表。可直接查看当前结果，明细与图像在进入对应页面后读取。

每次打开“数据看板”时根据已保存配置选择地址：未启用交互时读取本机；启用本机汇总时访问本机线体服务；启用远程交互时先检查已配置的中心网页，最多等待约 1.5 秒，不可访问时提示并打开本机归档。中心恢复后再次打开菜单会重新检查，不会更改已保存的服务器地址。“数据 → 本机数据”始终读取本机数据库；主控机的本机库也包含已接收的线体数据。页面右上角区分“本机归档”和“线体汇总”。已打开的查询窗口保留当前地址和范围，不强制跳转。

帮助和看板使用 WebView2 窗口。缺少运行环境时会提示安装 Microsoft Edge WebView2；右键菜单和开发者工具已关闭，页面内查询、复制和下载仍可用。关闭网页窗口不停止服务。关闭工位交互或主控汇总仍可查询本机历史，退出软件才停止本机归档和网页服务。

查询范围与自动更新

设置开始日期、结束日期、来源工位、完整膜卷号及料号，点击“查询数据”。日期两端均包含在内，单次最多 366 天；空白工位、卷号或料号表示全部。“当前卷”“当天”“近7天”“近60天”可快速切换范围。修改输入后需要查询才生效。

“数据来源”区分工位检测结果与中心计算结果，避免重复计算。左侧提供线体总览、工位统计、膜卷追溯、过程能力、瑕疵与图像、检测明细；页面共用已应用的查询条件。点击膜卷表中的卷号可缩小范围。

当前卷与当天默认每 5 秒检查服务状态，有新提交才刷新；历史范围默认关闭自动更新，可手动打开。当前卷模式随最近归档卷切换，手工筛选后固定所选条件。数据按批提交，页面与检测画面之间允许存在几秒延迟。

归档检测组是各工位上报组数之和，不代表产品片数。测量组通过率以含有效尺寸或错位判定的组为分母，任一明细为 NG 的组计入 NG；WARN 不计入 NG。瑕疵数量与有效检测图像分别统计，图像通过率不等于实际产品合格率。采样米段为已记录最大、最小米数的范围，不代表实际产量。

点击“进入数据大屏”显示深色统计布局，可通过页面按钮退出。工位统计显示当前连接状态、独立计数及最近归档缺口；连接状态不等于该工位当前正在检测。

尺寸与错位过程能力

在“过程能力”选择检测项，查看最近 2,000 点趋势、历史规格线、全量直方图、正态参考曲线、小时过程包络及能力矩阵。包络最多 2,000 个区间，超出后合并相邻区间，保留最小值、最大值和加权均值。指标依据全部有效样本计算，单位为 mm。

不同工位、料号、检测项、相机、面别、来源与规格分别计算。Cp／Cpk 使用同日、同卷、同会话和数据集内固定采集序号的非重叠 5 点子组，合并组内方差；至少需要 2 个完整子组。乱序补传仅补齐所属子组，不与最近实时样本混组。未满子组不参与组内估计。Pp／Ppk 使用全部有效样本的样本标准差。

少于 30 点仅供参考；无效规格、零波动或完整子组不足时相应能力指数显示“—”。不同检测项的 Cpk 不取平均。LSL／USL 为采集时规格限，不是控制限；正态曲线仅作分布参考。

瑕疵分布与关联图像

“瑕疵与图像”显示类型占比、横向位置与采集米数散点以及图片列表。位置图按需读取最近 2,000 处，图库每批读取 18 条；总览计数和分类占比使用全量摘要。多个卷查询时坐标会叠加，定位单卷问题时应选择完整卷号。判定名称为 OK 的候选不展示、不统计。

点击图像卡片查看关联图片及工位、相机、膜卷和位置。缩略图最长边为 480 像素，预览最长边为 4,096 像素。图片从记录对应工位的图像服务读取，数据库不保存图片内容；没有引用、来源工位离线或文件已清理时显示不可访问提示。

明细查询与 CSV 导出

在“检测明细”切换尺寸、错位和瑕疵，以游标分页读取记录。点击“导出 CSV”导出当前已应用条件下该类型的全部匹配明细，不限于当前页；导出期间避免重复点击。文本以公式符号开头时增加单引号，避免被电子表格作为公式执行。

过程 CSV 表头与字段

在系统设置中分别开启尺寸／瑕疵 CSV 保存，并检查对应路径。输出语言从“基本参数”独立选择，详见输出语言。非简体中文时，外文和中文位于同一单元格；含逗号、引号或换行的字段按 CSV 规则加引号。字段自身换行仍属于同一条记录，建议使用支持标准 CSV 的工具打开。

尺寸及错位测量值、标准值、公差偏差、补偿值的单位均为 mm。“上偏差／下偏差”保留原公差偏差数值，不代表标准值加公差后的绝对规格上限／下限；标准值、公差及补偿列仍由各自保存开关控制。英文采用 Std、Upper Dev、Lower Dev、Comp 等短表头。

界面有结果却找不到文件

  1. 核对过程 CSV、图像及报表各自的保存开关和路径。
  2. 按实际检测日期、料号和膜卷检查文件，换卷后报表仍归属旧卷。
  3. 检查磁盘空间、写入权限、自动清理及相同时段的保存错误。

看板无记录或图片不可访问

  1. 先通过“数据 → 本机数据”检查本机历史，核对数据库目录、磁盘空间及主程序运行状态；无数据时缩小日期、卷号和料号条件。
  2. 查看页面右上角数据范围。远程中心不可访问时会回到本机，不能将本机结果视为整条线体数据。
  3. 需要线体数据时，确认主控服务、网络地址和网页端口可达，再检查各工位唯一名称、交互启用状态及尺寸、瑕疵发送开关；这些发送开关不限制本机归档。
  4. 核对“工位检测结果／中心计算结果”，在工位统计查看归档队列错误和历史缺口。过期或超限数据不会无限补发。
  5. 缺图时先检查图片是否仍在保存目录；跨工位图片还需检查来源工位在线状态及图片端口。

查找本机结果

“数据”菜单还提供尺寸、瑕疵过程目录及图像目录入口。本机文件与中心看板分别保存，不能用其中一项存在推断所有输出均成功。

日志与异常检查

按相同时段搜索“本机历史数据服务已启动”“本机归档快照投递失败”“线体归档事务失败”“线体归档缓存淘汰”“线体网页查询失败”“工位图片服务启动失败”及“线体归档及网页服务启动失败”，保留完整异常，并核对服务地址、主控IP、端口、工位、卷号和磁盘路径。资料收集方法见日志与诊断。
