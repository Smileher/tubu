PLC 与系统控制器

先区分系统控制器与独立设备 PLC，再检查对应连接、型号、地址和数据类型。软件的尺寸结果、报警、纠偏、清米等输出各有条件，不能只凭“PLC 已连接”认定全部点位都在写入。

“系统设置 → 系统控制器 → 控制器连接”的启用状态保存后需重启生效。未启用时跳过该控制器连接、心跳、周期读取以及对应清米、编码器和采集门控，相关读写测试不可用；独立主 PLC 的原有业务不受此开关代替。

“调用结束”“写入已调度”“写入成功”和“设备实际动作完成”不是同一结果。排查时应逐层核对软件返回、PLC 点位和设备动作。

主设备 PLC 点位

在数据交互的主设备点位页，按生产信息读取、实时数据与控制输入、心跳与通信、软件与检测状态、闭环及专用业务信号分类设置；每项旁边说明读写方向、触发时机和格式。尺寸和瑕疵事件报警在“报警设置”中独立配置。

检测尺寸的料号输出与独立全部尺寸输出继续使用各自原有配置。控制器断连状态量继续同步“故障 1、正常 0”，与详细报警的断连事件地址独立，不使用报警保持时间。数据更新完成和点检超时停机等业务点位继续保留。

规格牌和详细报警的事件输出支持“地址|bool”“地址|int”“地址|float”，省略类型按 float 写入；人工复位命令在详细报警公共设置中单独选择类型。保持和复位行为参见PLC 报警保持时间。

无锡松下刻码

无锡松下现场使用专用刻码信号。启用双面检测并配置 AB 面相差笔数后，软件按相差方向配对两面的瑕疵和刻码尺寸：正数表示 A 面先到，负数表示 B 面先到。前面的未配对笔数会等待对应另一面到齐，配对完成后只发送一条刻码信息。

多同步组场景会等待完整批次再发送，避免同一物料由局部结果重复触发。刻码内容写入成功后才输出检测 NG 信号；检查时应同时核对刻码内容地址、检测功能地址、数据交互开关和 PLC 通信状态。

修改料号、换卷、停止检测或调整 AB 相差笔数后，应重新确认配对状态从新批次开始。出现等待超时、帧序列中断或 PLC 写入失败时，结合通信日志检查当前批次是否被丢弃以及地址配置是否正确。

MES 通信

在 MES 页核对启用状态和连接配置。保存后核对实际启用状态；启动时发现相关配置开关不一致，会按关闭优先处理并记录日志。

检查上传时，核对具体接口、请求时间、膜卷号、返回内容和本地待处理文件。启用功能、连接成功和业务上传成功需要分别确认。

部分项目使用共享文件获取卷号或项目专用上传接口，按对应项目约定配置；通用排查仍从路径权限、读取结果和接口返回开始。

珠海冠宇 mom

现场名称为 zhgy6c 或 zhgy8c 时，均使用“MES 配置”中的“珠海冠宇 mom”页面，读取同一套已有 MOM 配置，维护启用状态、厂部、数据类型、上传频率（完整批次数）、超时秒数和七项接口的完整地址。设备编号自动读取主程序已有的本机配置，在此只读显示，每台电脑使用自己的编号。厂部默认“6部”，可以按现场 MOM 要求修改；已有非空厂部配置继续保留。仅上传本机启用的尺寸、错位数据。修改配置前先停止检测，保存后重新刷卡验证；各接口地址需与现场 MOM 服务一致。

页面上方为七项接口表格及运行参数，设备编号、厂部、数据类型、上传频率和超时使用紧凑输入框，空间不足时自动换行。下方左侧集中显示服务器连接、接口测试和执行结果，右侧对照显示请求与返回报文；宽屏下两份报文并排显示，普通窗口上下显示。服务器 IP、端口与连接测试按钮同行，测试卡号与刷卡验证按钮同行。点击接口行可切换查看该项结果；窄窗口下诊断区域上下排列。七项接口分别勾选启用，修改后点击“保存配置”生效；旧配置未包含接口开关时沿用全部启用。关闭某项后跳过对应调用：人员资质校验关闭时仍按本地卡号查找用户及角色；参数请求关闭时保留当前料号；生产开始、结束关闭时跳过相应 MOM 通知；上传和人员操作日志关闭时停止对应发送。接口仍启用时，MOM 拒绝或网络失败继续按原规则处理。

上游接口关闭导致缺少 MOM 员工工号、工单、产品或批次时，不编造字段；跳过无法组包的下游接口并显示缺项，继续本地检测。本地账号或角色不存在仍不能刷卡登录，停用接口不能代替用户数据恢复。

zhgy6c 的服务器 IP、端口从已保存且启用的接口完整地址读取，只读显示；修改接口地址后需保存。软件启动、启用 MOM 或保存配置后立即检查，之后每 10 秒自动复查；每个目标最长检测 3 秒，不阻塞界面。同一主机、同一端口只检查一次，多个目标并行检测，全部可达才表示正常。点击“测试连接”立即执行同一检查，与当前选中接口无关；页面列出各目标结果和最近完成时间。检测只建立 TCP 连接，不发送 HTTP、人员校验或生产报文，也不恢复上次生产会话；重启或保存配置后仍需正式刷卡再开始生产。未写端口的 HTTP 地址使用 80，HTTPS 使用 443。

zhgy8c 的“测试连接”继续使用页面可编辑的 IP、端口，仅作为独立 TCP 工具，不改写接口地址、不保存测试地址、不改变底灯。两种现场均需分别查看网络、HTTP 和业务结果；端口可达不代表接口路径、人员资质、工单或上传成功。

填写测试卡号后可执行“刷卡验证测试”：先检查本地用户及角色，再请求 MOM；只显示验证结果，不建立登录会话、不缓存生产员工身份，正式生产前仍需在主界面刷卡。“参数查询预览”只显示返回公差，不覆盖料号、不执行换型或办理生产开始。测试和保存均使用现有权限确认；刷卡及参数测试读取已保存接口配置，六厂服务器 TCP 检测读取已保存且启用的接口地址，八厂读取页面 IP、端口。其它接口通过正常启停、实测上传和操作日志流程验证，不提供手动办理批次或上传测试数据的按钮。

“执行结果”区的“查看运行日志”打开现有软件日志目录，可按日期查看：Debug 保存实际 MOM 请求和返回，Error 保存异常、超时及技术告警，Records 保存刷卡认证和人员操作。页面的执行结果是当前接口最近一次记录，不能代替历史日志；六厂 TCP 检测结果同时更新页面和底灯，八厂独立 TCP 测试结果仅显示在页面。

zhgy6c 底灯绿灯明确表示“MOM服务器端口可达”，仅在全部启用目标均可达时点亮；任一目标失败显示红色“MOM服务器端口不可达”，地址或配置异常显示红色“MOM服务器配置异常”。首次检测短暂显示灰色“MOM服务器检查中”，没有启用接口时显示灰色“MOM接口未启用”；周期复查期间保留上次结果，避免闪灯。网络恢复后自动更新，后台检测失败不反复弹窗。HTTP 错误、MOM 业务拒绝及本地参数校验失败仍查看对应接口；服务器端口状态独立于业务通信记录及 PLC 蓝灯控制。

zhgy8c 底部“MOM未验证”仍以灰色表示尚无 HTTP 通信结果；收到 HTTP 响应后“MOM通信”显示绿色，请求网络失败显示红色。HTTP 错误码或业务拒绝不等于端口断开，仍需查看分阶段结果。

zhgy6c 手动开始或结束遇到 MOM 错误时，提示框显示原因、现场处理步骤及当前检测状态。开始检查失败时检测未启动；结束检查失败时检测继续运行。参数公差异常按编码汇总名称、标准值、上下限及单位，需联系 MOM／工艺负责人核对数据和本机测量项编码，修正后在“参数查询预览”复核，再重新开始检测。标准值必须为有效数值且在上下限范围内，不提供忽略校验入口。人员权限异常应核对员工状态与设备授权；缺工号需正式刷卡，缺工单或批次需核对参数接口启用状态及返回字段；网络错误先测试端口，再查看 HTTP 和业务返回。

人员资质校验启用时，刷卡时先按卡号查找本地用户及角色，再将卡号和设备编号直接发送到 MOM。只有 MOM 返回成功才完成登录，权限继续使用该用户已有的本地角色。卡号不存在、MOM 拒绝或请求超时均不允许本次刷卡登录；原有密码登录和启动自动登录方式保留。生产接口需要 MOM 返回的员工工号，未取得时按提示先刷卡验证。

  1. 启用 MES 后，手动点击“开始”会依次执行已启用接口：获取产品参数、直接保存到当前料号、查询 MOM 换型完成状态、请求生产开始，全部成功后启动检测。
  2. 下发参数按宽度及错位的 NG 编码匹配本机启用项，直接覆盖标准值和上下限，无需人工确认。未匹配项及其它参数保留；匹配编码冲突、公差无效或保存失败会提示原因并阻止启动。已成功保存的参数在后续换型或生产校验失败时仍保留。
  3. 过程参数按现有 MES 笔数频率上传，报文保留本次生产的工单、批次和生产开始时取得的 MOM 员工工号；界面自动注销不改变已开始生产的数据归属。判定 WARN 按 OK 上传；上传失败记录原始请求、返回和原因，继续处理后续数据，不自动补传。
  4. 生产结束接口启用时，手动点击“停止”先请求 MOM 生产结束，成功后停止检测；MOM 返回 NG 或请求超时时保持检测运行并显示原因。MOM 的生产结束代表批次完工，暂停检测前应确认该批次可以结束。

人员操作日志按操作发生时的身份上传，操作时间使用 UTC。排查时区分刷卡、参数请求、换型校验、生产开始、过程参数上传、生产结束和操作日志七项业务，保存各自的请求时间、完整地址和原始返回。MOM 返回的 Result 决定业务成功与否，HTTP 连接成功不能代替业务确认。

自动启动及自动／故障停止继续执行原有控制流程；上述 MOM 生产开始、结束校验对应手动启停。现场联调还需核对换型及批次状态、实际参数编码、工单和员工工号。

配置尺寸输出

“数据交互 → 尺寸交互功能”默认打开“全部尺寸（推荐）”。新建测量值输出优先使用此页，可从五组尺寸数据集和三组错位数据集中任选，支持本机检测数据与工位交互接收的数据。

  1. 点击“新增尺寸”，选择适用数据集。
  2. 填写该数据集中的尺寸或错位名称，以及测量值 PLC 地址。名称需一致；没有匹配数据时不写入。
  3. 勾选“启用”并点击页面底部“保存”。PLC 连接正常时，后台每 5 秒读取并发送最新值；上一轮未结束时跳过本轮，不叠加发送任务。

地址支持“地址|float”或“地址|int”；不写类型时按 float 处理。int 将测量值乘以 100 后四舍五入，供接收端按比例还原。

“料号尺寸（旧版）”保留当前料号的尺寸、错位输出配置，包括测量值、标准值、上下限、补偿及状态等原有字段。需要这些字段时仍在此页设置。两页配置独立保存，不会自动迁移或停用旧地址；避免两页同时向同一地址输出。新增尺寸也不会自动补齐输出地址。

控制器读写与通信排查

在“系统设置 → 系统控制器”检查型号、IP 或串口，再检查各点位的读写方向。读写测试使用“地址|类型”，类型为 int、bool 或 float，并填写与类型一致的值。

手动写入会影响真实设备点位，测试前应确认设备状态和目标地址。系统控制器未启用时，参数下发和读写测试不可用。

MES 上传失败时，分别核对功能启用、网络连接、接口请求与返回。卷号获取、数据上传、登录或日志上报是不同业务，单个接口成功不能代表其他接口也成功。

连接正常但没有输出

检查顺序需要确认
1. 连接对象主设备 PLC、系统控制器、纠偏设备和 MES 是不同对象，检查实际输出使用的通道。
2. 触发条件报警是否达到计数条件，纠偏是否满足采样与许可，尺寸输出是否有匹配的有效数据。
3. 点位及格式核对地址、读写方向、float／int／bool，以及对应功能的缩放规则；不要将全部尺寸的四舍五入与纠偏的截断混用。
4. 本次返回查看同一时刻的发送结果与错误，不以历史连接成功替代本次写入确认。
5. 接收与设备软件报告写入成功后，继续确认 PLC 中的值、设备许可和接收端处理。

以“全部尺寸”为例，显示 12.345 时，float 输出保留测量数值，int 输出将值乘以 100 后四舍五入。接收端必须按同一比例解释。该示例不能套用到报警布尔信号或其他通信功能。

MES 上传失败保留哪些信息

  • 记录发生时间、接口用途、料号与卷号，区分卷号读取、生产数据上传和文件通知。
  • 保留本次返回码、返回正文及软件错误，不只记录“网络正常”。
  • 核对本地待处理文件是否生成；文件同步和 MES 业务确认属于不同环节。
  • 项目专用接口按该接口要求处理，不能以一个接口成功推断全部业务已完成。
