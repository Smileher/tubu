MES 通信

通用 MES 使用一份主配置，支持 TCP、HTTP、MQTT，分别配置尺寸过程上传和瑕疵过程上传。尺寸包含现有尺寸与错位数据。料号切换使用同一份通用 MES 配置。

  1. 打开“MES 配置”，核对“启用 MES”、协议和连接参数。HTTP 在选中接口后填写对应的完整 URL；TCP、MQTT 填写主机名或 IP 和 1～65535 的端口。
  2. 选择“尺寸过程上传”或“瑕疵过程上传”，勾选对应的“启用尺寸上传”或“启用瑕疵上传”。新建配置默认使用模板替换，也可切换为固定格式；两种模式分别保留编辑内容，已有配置按保存的模式打开。
  3. 配置参数来源，点击右侧“检查配置”，再用“测试发送”检查返回结果。运行中可以编辑、检查和测试；停止检测且待上传任务处理结束后，点击“保存并应用”。保存继续按现有权限确认。

应用成功后更新生产连接。保存成功不代表服务器可达；断连时检查目标及返回原因。MES 总开关与主配置开关同步；启动时发现不一致，按关闭优先处理并记录日志。

协议 设置与核对
HTTP 填写 http:// 或 https:// 开头的完整地址。正文方式包括“JSON（UTF-8 无 BOM）”“表单字段”和“JSON（UTF-8 带 BOM）”，新配置默认无 BOM。表单方式需填写承载正文的字段名；带 BOM 方式的正文开头包含 UTF-8 字节序标记，按接收方要求选择。HTTP 不要求 Ping 成功，以实际请求结果判断。
TCP 普通正文用 UTF-8；“专用报文封装”用 GB2312，格式为 STX + 消息序号 + TAB + 设备名称 + TAB + 命令标识 + TAB + 正文 + ETX。STX 为 0x02，TAB 为 0x09，ETX 为 0x03；勾选封装后才显示设备名称及当前接口的命令，尺寸与瑕疵命令分别设置。
MQTT 填写客户端标识、认证信息和发布主题；发布主题不能含 + 或 # 通配符。仅发布上传报文，不配置订阅。

MES 上传频率与瑕疵范围

尺寸接口显示“每 X 笔发送 1 次”，每笔按全部同步组到齐后的完整批次累计，不是时间间隔，X 至少为 1。瑕疵接口只显示“仅发送首个瑕疵”，无瑕疵时不发送瑕疵明细；未勾选时，每个瑕疵分别生成一份报文；勾选后只上传该笔现有列表中的第一个，不排序、不跨笔合并。

首个选项只影响明细上传，不减少参与检测与计数的瑕疵。按工艺选择首个或全部明细并保存；共享文件结束状态和膜卷号归属也会影响是否发送。

MES 测试与配置文件

  1. 进入页面或切换接口后自动填充测试数据，无需先点击模拟：按当前料号模拟一笔尺寸、错位和瑕疵；补偿、标准值和上下限保留配置参数，已收到的交互项使用缓存中的参数，只有预设名称且没有参数的交互项按默认参数模拟。模拟结果包含默认补偿和现补偿，不改写生产数据。
  2. 时间、设备编号、膜卷号、速度、米数、账户等使用当前真实快照。测试行按模板中变量首次出现的顺序排列，包括固定值；重复变量只显示一行，不同变量即使来源相同也可分别修改。点击测试值即可连续输入，无需双击进入单元格编辑。悬浮查看来源，“状态”列标出自动、固定值、缺省值、手动或缺项。未绑定项需先设置来源；来源缺值时可配置缺省值，或仅为本次测试手动填写。手动测试值不会修复或保存为生产来源。
  3. 测试值填充后保持固定，更换某项绑定后该项重新填充；收到料号或膜卷号更新通知后重新填充自动值，其余绑定未变的手动值保留。
  4. 点击“测试发送”，自动填充参数、生成报文，使用独立连接向当前目标发送，MQTT 测试使用临时客户端标识以避免挤掉生产连接；无需先生成预览；结果显示目标、耗时、返回或失败原因。测试会产生真实请求，使用前核对目标服务器及主题。

TCP 写入完成、MQTT 发布完成、HTTP 成功状态和 MES 业务接受是不同结果；通用 TCP 未定义业务应答时只能确认已写入连接。HTTP 显示实际状态码和返回正文，带 BOM 方式也会保留错误返回；返回正文仍需按接收方约定核对。独立测试成功不能代替生产通道验证。

“导入配置”只加载编辑副本，显示校验提示，保存前不改变生产配置。“导出配置”校验并导出当前编辑内容，不应用配置，不能直接覆盖生产主文件。唯一通用主文件仍为 MesConfig.xml；读取不会改写原文件，保存失败保留原文件，成功替换时保留 .bak 备份。

仅使用当前页面支持的 TCP、HTTP、MQTT 协议；HTTP 填写完整接口 URL。导入失败时保留当前有效配置，按提示修正后重新导入。

MES 上传失败保留哪些信息

  • 记录发生时间、接口用途、料号与膜卷号，区分膜卷号读取、生产数据上传和文件通知。
  • 保留本次返回码、返回正文及软件错误，不只记录“网络正常”。
  • 核对本地待处理文件是否生成；文件同步和 MES 业务确认属于不同环节。
  • 项目专用接口按该接口要求处理，不能以一个接口成功推断全部业务已完成。

日志与异常检查

先查看当前接口的目标、耗时、HTTP 状态及业务返回，再查同一接口与膜卷号的日志。测试请求、生产发送和业务接受分别判断；不能用网络连通或历史成功记录代替本次上传结果。
