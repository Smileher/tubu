设置与确认顺序

  1. 准备当前相机图像，先添加并启用碳膜区域，检查定位。
  2. 进入“涂膜检测 → 特定瑕疵预检测”，按需要启用亮瑕疵、暗瑕疵并设置参数。
  3. 执行“本项试检”，核对轮廓、测量值及过滤原因。
  4. 再执行整图试检，确认各区域是否继续参与后续检测，最后统一保存。

特定瑕疵预检测

进入“涂膜检测 → 特定瑕疵预检测”。此功能替代原削薄检测，直接使用当前相机已添加并启用的碳膜区域。先配置碳膜区域及定位，再分别勾选“启用亮瑕疵检测”“启用暗瑕疵检测”，设置对应的面积范围（mm²）、纵向最小长度（mm）、灰度范围和瑕疵名称。两类开关默认均关闭，默认名称分别为“亮瑕疵”“暗瑕疵”。

参数独立于“区域亮暗瑕疵检测”和历史削薄参数，历史值不自动复制。“最大检出个数”为1～100的整数，默认2；每个碳膜区域的亮、暗瑕疵分别计数，按连通域实际面积从大到小保留前N个，面积相同时保持原顺序。面积和最小长度条件同时满足才保留候选。

亮、暗瑕疵的红色标注沿实际检出区域的边界绘制，包含孔洞边界。分项试检、整图试检、在线显示、点检及启用的NG标注预览使用相同轮廓；缩放和平移后仍与图像位置对应。碳膜检测区域的定位框继续按原设置显示。结果表的面积、长宽、起止坐标仍沿用原测量口径，起止行列表示外接范围；原图和瑕疵小图的裁剪、像素内容保持原样。轮廓显示异常会记录原因，不改变检测结论，也不触发该区域重新检测。

点击本页“本项试检”只试检预检测，使用当前相机尚未保存的参数与定位区域草稿，无需标准模板或碳膜AI模型。参数自动换行并完整展开；统一保存后，在线和点检使用正式配置。此功能适用于现有HALCON碳膜检测体系。

在线、整图试检和点检先对各碳膜区域执行已启用的预检测。两类都开启时，两类均检测完成；某个区域任一类检出合格瑕疵，该区域就跳过后续传统或AI碳膜瑕疵检测，其他通过预检测的区域继续按原流程检测。跳过状态仅用于当前帧，不改变区域启用设置。全部区域均被预检测判为NG时，直接使用预检测结果；仍有区域需要碳膜检测时，继续执行原标准模板和模型检查。

预检测检查定位后的完整碳膜区域，碳膜专有的边缘灰度、类别屏蔽继续作用于后续碳膜算法。预检测结果沿用尺寸修正、二次分类、图像、统计和输出流程；任一阶段得到 OK 即忽略该候选，不产生区域 NG 跳过状态。一个区域的预检测结果全部被忽略时，该区域继续普通碳膜检测；仍有正式瑕疵保留时才跳过。离线以绿色标明 OK 的忽略阶段，在线不显示或记录该候选。参数无效或预检测异常时记录原因，未成功完成预检测的区域仍执行原碳膜流程。

需要预检测时，在碳膜检测入口添加并启用碳膜区域，再配置并保存本页参数。两个预检测开关均关闭时，执行普通碳膜检测流程。

日志与异常检查

使用试检的“过滤/保留说明”查看面积、长度、数量筛选及最终忽略原因；在线异常查同一帧的 Error。参数无效或预检测异常与“没有检出缺陷”不同，应先核对区域和原始提示。
