PLC 与系统控制器

先区分系统控制器与独立设备 PLC，再检查对应连接、型号、地址和数据类型。软件的尺寸结果、报警、纠偏、清米等输出各有条件，不能只凭“PLC 已连接”认定全部点位都在写入。

“系统设置 → 系统控制器 → 控制器连接”的启用状态保存后需重启生效。未启用时跳过该控制器连接、心跳、周期读取以及对应清米、编码器和采集门控，相关读写测试不可用；独立主 PLC 的原有业务不受此开关代替。

“调用结束”“写入已调度”“写入成功”和“设备实际动作完成”不是同一结果。排查时应逐层核对软件返回、PLC 点位和设备动作。

主设备 PLC 点位

在数据交互的主设备点位页，按生产信息读取、实时数据与控制输入、心跳与通信、软件与检测状态、闭环及专用业务信号分类设置；每项旁边说明读写方向、触发时机和格式。尺寸和瑕疵事件报警在“报警设置”中独立配置。

检测尺寸的料号输出与独立全部尺寸输出继续使用各自原有配置。控制器断连状态量继续同步“故障 1、正常 0”，与详细报警的断连事件地址独立，不使用报警保持时间。数据更新完成和点检超时停机等业务点位继续保留。

规格牌和详细报警的事件输出支持“地址|bool”“地址|int”“地址|float”，省略类型按 float 写入；人工复位命令在详细报警公共设置中单独选择类型。保持和复位行为参见PLC 报警保持时间。

无锡松下刻码

无锡松下现场使用专用刻码信号。启用双面检测并配置 AB 面相差笔数后，软件按相差方向配对两面的瑕疵和刻码尺寸：正数表示 A 面先到，负数表示 B 面先到。前面的未配对笔数会等待对应另一面到齐，配对完成后只发送一条刻码信息。

多同步组场景会等待完整批次再发送，避免同一物料由局部结果重复触发。刻码内容写入成功后才输出检测 NG 信号；检查时应同时核对刻码内容地址、检测功能地址、数据交互开关和 PLC 通信状态。

修改料号、换卷、停止检测或调整 AB 相差笔数后，应重新确认配对状态从新批次开始。出现等待超时、帧序列中断或 PLC 写入失败时，结合通信日志检查当前批次是否被丢弃以及地址配置是否正确。

MES 通信

在 MES 页核对启用状态和连接配置。保存后核对实际启用状态；启动时发现相关配置开关不一致，会按关闭优先处理并记录日志。

检查上传时，核对具体接口、请求时间、膜卷号、返回内容和本地待处理文件。启用功能、连接成功和业务上传成功需要分别确认。

部分项目使用共享文件获取卷号或项目专用上传接口，按对应项目约定配置；通用排查仍从路径权限、读取结果和接口返回开始。

配置尺寸输出

“数据交互 → 尺寸交互功能”默认打开“全部尺寸（推荐）”。新建测量值输出优先使用此页，可从五组尺寸数据集和三组错位数据集中任选，支持本机检测数据与工位交互接收的数据。

  1. 点击“新增尺寸”，选择适用数据集。
  2. 填写该数据集中的尺寸或错位名称，以及测量值 PLC 地址。名称需一致；没有匹配数据时不写入。
  3. 勾选“启用”并点击页面底部“保存”。PLC 连接正常时，后台每 5 秒读取并发送最新值；上一轮未结束时跳过本轮，不叠加发送任务。

地址支持“地址|float”或“地址|int”；不写类型时按 float 处理。int 将测量值乘以 100 后四舍五入，供接收端按比例还原。

“料号尺寸（旧版）”保留当前料号的尺寸、错位输出配置，包括测量值、标准值、上下限、补偿及状态等原有字段。需要这些字段时仍在此页设置。两页配置独立保存，不会自动迁移或停用旧地址；避免两页同时向同一地址输出。新增尺寸也不会自动补齐输出地址。

控制器读写与通信排查

在“系统设置 → 系统控制器”检查型号、IP 或串口，再检查各点位的读写方向。读写测试使用“地址|类型”，类型为 int、bool 或 float，并填写与类型一致的值。

手动写入会影响真实设备点位，测试前应确认设备状态和目标地址。系统控制器未启用时，参数下发和读写测试不可用。

MES 上传失败时，分别核对功能启用、网络连接、接口请求与返回。卷号获取、数据上传、登录或日志上报是不同业务，单个接口成功不能代表其他接口也成功。

连接正常但没有输出

检查顺序需要确认
1. 连接对象主设备 PLC、系统控制器、纠偏设备和 MES 是不同对象，检查实际输出使用的通道。
2. 触发条件报警是否达到计数条件，纠偏是否满足采样与许可，尺寸输出是否有匹配的有效数据。
3. 点位及格式核对地址、读写方向、float／int／bool，以及对应功能的缩放规则；不要将全部尺寸的四舍五入与纠偏的截断混用。
4. 本次返回查看同一时刻的发送结果与错误，不以历史连接成功替代本次写入确认。
5. 接收与设备软件报告写入成功后，继续确认 PLC 中的值、设备许可和接收端处理。

以“全部尺寸”为例，显示 12.345 时，float 输出保留测量数值，int 输出将值乘以 100 后四舍五入。接收端必须按同一比例解释。该示例不能套用到报警布尔信号或其他通信功能。

MES 上传失败保留哪些信息

  • 记录发生时间、接口用途、料号与卷号，区分卷号读取、生产数据上传和文件通知。
  • 保留本次返回码、返回正文及软件错误，不只记录“网络正常”。
  • 核对本地待处理文件是否生成；文件同步和 MES 业务确认属于不同环节。
  • 项目专用接口按该接口要求处理，不能以一个接口成功推断全部业务已完成。
