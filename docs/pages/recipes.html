创建与管理料号

进入“料号管理”，使用添加料号、已有模板或料号创建引导建立新料号。模板提供初始参数，仍需重新核对相机、标定、尺寸、定位边缘和瑕疵区域。

使用料号创建引导时，按页面步骤准备相机图像、定位边、工艺抓边、尺寸错位及瑕疵注册；最后核对生成结果，再创建和切换。

删除料号前确认选择正确。当前正在使用的料号不能删除。复制料号后，应重新检查模板注册状态；软件内复制的新副本需要重新注册瑕疵模板。

切换料号

  1. 选中目标料号，点击“应用料号”并确认。
  2. 如有未保存参数或统计设置，先按提示保存、放弃或取消切换。
  3. 等待旧数据清理、料号保存、模块通知和相机初始化结束。不要在进度尚未结束时重复应用。
  4. 核对主页的当前料号、相机状态和检测参数，按软件最终提示处理。

目标已经是当前料号时，不会重复切换。若切换失败，应读取具体阶段提示和日志，不能仅凭列表选中项判断切换已成功。

页面草稿与保存

尺寸、瑕疵、料号管理和参数补偿各自保留页面草稿。修改输入不等于正式配置已经生效，点击当前页面的保存按钮才会提交该页面负责的参数。

  • 保存会先检查输入和当前功能要求；需要检测成功或算子顺序有效时，仍须完成对应检查。
  • 保存以最新正式配置为基础，保留其他页面的最新值。同一参数被其他操作同时改成不同值时，会拒绝覆盖并提示冲突。
  • 保存失败时保留当前修改；先查看原因，再选择修正、重新读取或取消，不反复覆盖配置文件。
  • 重新进入页面时读取最新已提交参数。尺寸页保存成功后保留当前图像、视野和页签。

若提示“料号已保存，但系统配置保存失败”，料号部分已经生效。按提示重试系统配置，不应认为全部内容都已回滚。

离开页面时的三种选择

选择结果
保存并离开先检查并保存本页参数；成功后离开，失败则继续停留。
不保存并离开丢弃本页草稿，保留之前已经正式保存的配置。
继续编辑保留当前输入并留在页面；关闭提示框或按 Esc 也继续编辑。

补偿页内“保存”只提交当前数据集；离开补偿页选择保存时，会一次提交本页全部有修改的数据集。直接绑定到系统设置的独立开关，不属于料号草稿，不会因为放弃料号修改而回滚。

如何确认参数生效

先确认保存成功提示，再重新查看相关参数或执行试检。在线抓边窗口的保存会立即提交当前相机实际修改的抓边字段，后续帧使用新配置；已开始计算的帧仍可能使用原快照。

某些系统连接设置要求重启后生效，例如“系统控制器 → 控制器连接 → 启用”。相机自动取流策略在下次成功启动检测时生效。以各功能说明和界面提示为准，不能统一理解为“点保存后所有设备立即重连”。

使用料号创建引导

未关联相机可使用默认左端线，无需单独标零；关联相机及多相机拼接应先核对手动标零直线。运行允许缺省左端线，不代表引导可以跳过实际拼接基准校验。

  1. 点击“料号创建引导”，选择工位检测能力、料号名称、来料工艺、碳膜数量、双面及陶瓷选项，并勾选使用相机。
  2. 按工艺填写极耳、碳膜、陶瓷或涂料宽度，检查 A/B 面的对应关系。
  3. 为相机加载或获取图像，放置定位 ROI 并抓取箔材定位边。
  4. 进入生成预览，逐相机检查工艺抓边、尺寸与错位，必要时重新抓取当前边。
  5. 瑕疵检测所需图像应为标准无缺陷图，完成注册后核对最终创建项目。
  6. 确认后点击“创建并切换”，等待结束，再检查当前料号、图像和检测配置。

引导生成的是初始配置，不能省略实际图像核对。宽度、公差和面别应与产品实际工艺一致，不用示意图外观代替测量确认。

导入、导出与备份

“导出料号”用于保存选中料号，“导出全部料号”用于批量备份；“导入料号”从已有文件恢复配置。应用前核对料号名称、相机和实际设备条件，不能因为导入成功就认为模板、标定和设备连接都适用。

料号参数中的双面检测、涂布模式、自定义虚拟图和 MES 跟随选项会影响后续使用。修改后点击“保存料号”，并在对应功能页检查结果。系统级设备配置仍使用系统设置中的独立保存入口。

间隔涂布选择“间涂”并保存后，从“瑕疵工具 → 间涂配置”设置各相机的拼图检测或屏蔽间隙模式，详见间隔涂布设置。连涂模式下这两个功能关闭，入口隐藏。

保存失败、冲突与部分成功

现象怎样判断下一步
输入后结果没有变化当前值可能仍是页面草稿，或该设置需重新启动检测、重启软件。核对本页保存提示与对应生效说明，再试检。
提示参数在其他位置修改同一字段存在并发修改，软件拒绝覆盖最新正式值。先记录当前输入，重新进入页面读取正式配置，再决定需要保留的值。
料号已保存，但系统配置保存失败料号与系统配置是不同保存结果。核对料号已保存部分，按提示处理系统配置，不重复导入整套旧料号。
导出文件成功导出完成只说明备份或表单已生成。仍核对正式保存提示，不能以导出成功代替保存。

应用料号前，建议先导出当前可用料号。切换结束后检查相机、面别、测量名称及模板，不只看料号列表是否选中。
