管理相机配置

进入相机配置，选择相机后使用添加、修改或删除按钮，完成后点击“保存相机配置”。先核对驱动类型和设备连接参数，再保存。

相机配置页面保存与料号参数保存是不同入口。保存成功后按提示重启软件使连接配置生效，再获取图像确认。

连接与取图

配置相机前，先确认驱动类型和设备在厂商工具中的真实名称、地址或索引。不同驱动使用不同字段，不能把“设备名称”统一当成 IP。

常见驱动连接字段要点
海康 GigE通过相机 IPv4 地址选择设备。
DALSA Camlink采集服务器和采集资源索引用于采集卡；可选相机控制使用单独的设备服务器和控制资源索引。
ITEK GigE / DVP按 SDK 用户自定义名称选择设备。
CXP ITEK软件显示名称须与设备的用户自定义名称一致。
本地相机按本地图片和采集间隔进行模拟，不能据此确认真实相机通信正常。

进入尺寸或瑕疵设置时，先选择当前相机，再获取或加载图像。没有有效图像时先解决采集或图片加载问题，不用其他相机的图像代替当前相机。

跟随运动自动取流

部分项目提供“相机自动取流”，可按速度、米数或脉冲判断运动。保存策略后，下次成功启动检测时生效；目前该功能用于正运动系统控制器。

持续静止后软件自动停流，有效运动恢复后重新启流。自动停流期间检测仍可显示运行中。读取无效时保持当前取流状态；自动动作失败会暂停本轮控制，处理提示后停止并重新启动检测。

没有图像或图像顺序异常

  1. 记录相机名称、驱动、异常时间及设备是否正在运动。
  2. 检查连接状态、触发信号、光源和自动取流状态，区分“未连接”“已连接但未取流”“有帧但图像不正确”。
  3. 查看当天 Error 中的相机、SDK、阶段和错误码；初始化失败时保留“相机 SDK 加载异常”提示。
  4. 自动启停问题搜索 CameraAutoCapture，按轮次和操作编号关联开始、逐相机返回和完成日志。

采集卡返回成功不一定包含相机控制命令的结果。需要同时检查相机命令和触发门控记录，而不能仅凭一条“启流完成”判断所有环节正常。

新增或修改相机

  1. 停止检测，在“系统设置 → 相机管理 → 相机配置”选择添加或修改相机。
  2. 核对软件显示名称、驱动类型、面别、显示顺序和设备选择字段。
  3. 按当前驱动提示填写名称、IP、设备索引或采集资源；使用厂商工具核实真实值。
  4. 点击“保存相机配置”，按提示重启软件。
  5. 重启后检查加载提示，再在参数页选择相机获取图像，确认方向、幅面、曝光与触发条件。

更换相机、分辨率或安装位置后，继续检查标定标零、定位区域和注册模板。软件显示名称与物理设备名称的用途因驱动不同，不能随意互换。

采集状态怎样区分

现象检查方向
初始化失败驱动运行库、设备名称、IP、板卡或资源索引、设备占用，以及原始错误码。
已连接但不出图是否启流、触发源、设备是否运动、门控、曝光与光源。
出图但黑屏或花图像素格式、图像大小、曝光、照明、接线和厂商工具中的图像。
图像正常但没有检测运行状态、当前料号相机是否启用、必要模型和模板，以及检测阶段错误。

逐相机检查，避免因另一台相机正常就判断全部采集已就绪。与采集相关的初次加载错误会汇总提示，后续问题查看当天错误日志。

先区分连接、取流与检测

状态含义下一步
未连接尚未建立相机或采集卡连接。检查驱动、设备选择、线路与初始化错误。
已连接但没有新帧连接成功不等于触发和取流均正常。检查触发源、材料运动、采集门控及自动停流状态。
有新帧但无有效结果采集已发生，检测可能失败或未启用对应项目。核对图像内容、料号、抓边、检测区域与本帧错误。
提示自动取流已暂停本轮自动动作失败后不继续自动重试。保留逐相机结果，处理原因，再手动停止并重新启动检测。

“设备持续无有效运动，相机已自动停止取流，检测仍在运行。”是自动策略提示，不等同于手动停止检测。恢复运动后仍未出图时，再检查控制器数据与逐相机动作结果。
