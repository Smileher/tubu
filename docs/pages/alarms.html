报警设置：规格牌与详细报警

“报警设置”分为规格牌、详细报警等页面。“规格牌”配置尺寸和瑕疵规则，可保存、导入导出及跟随料号；主界面顶部的规格牌快捷窗口使用同一组规则。“写入 PLC”控制事件输出，点位填写在“PLC 地址”中。

“详细报警”使用同页分组布局：页首集中设置 PLC 输出与人工复位的公共参数；左侧为常用检测报警、开检与运行提示，右侧为设备与采集监控，页底按位置与尺寸、文字与颜色、显示与预览配置报警弹窗。每项的启用、阈值和 PLC 地址保持在同一行，使用固定在底部的“保存详细报警”统一保存。设备断连报警按故障类型和监控对象分别跟踪，同一次持续故障只通知一次，恢复后再次故障可重新触发；原有故障停止流程继续执行。

检测声光报警

“尺寸声光报警”控制本机生产尺寸及错位 NG 的三色灯和蜂鸣器；“瑕疵声光报警”控制本机瑕疵 NG 的三色灯和蜂鸣器。两项分别生效，均不控制界面 OK/NG 显示，也不代替规格牌、详细报警或独立 PLC 输出规则。

符合所启用类别的每次 NG 都立即触发红灯和蜂鸣器，并从这次 NG 起重新保持 3 秒。连续 NG 持续续期，期间收到 OK 不提前解除声光；到期后运行中恢复绿灯，停止后按停止状态处理。规格牌仍使用其独立的“声光”选项与触发规则。

五项检测报警计数

尺寸连续超差、尺寸累计超差、瑕疵连续检出、瑕疵累计检出均按检测次数计数，一次检测检出多个瑕疵也只计一次。区域瑕疵累计报警按相机和膜区分别累计瑕疵个数。连续计数在本次正常时归零，累计计数继续保留；达到阈值后提示、按配置写入 PLC，并清零对应计数。

这些规则沿用连续／累计计数，不采用规格牌的窗口规则。报警计数只保存在内存；换卷和人工报警复位清空规格牌及上述五项计数，旧代次结果不会重新累加到新计数中。同一卷号重复读取不清零。

PLC 报警保持时间

在“详细报警”页首的“PLC 输出与人工复位 · 公共参数”配置保持策略。默认不勾选“自动复位 PLC 输出”，触发时只写入 1，不主动清零；勾选后，写入 1 成功才开始计时，到期写入 0。保持时间默认 100 毫秒，范围 1～60000 毫秒，由规格牌、详细报警和人工复位命令共用。

同一 PLC 的同一实际地址保持期间，重复触发合并，不再次写入 1，也不延长时间；不同地址独立计时。更改配置、停检测、换卷或关闭页面不改变已安排的复位。故障恢复本身不自动清零；写入或定时复位失败会提示并记录日志，不自动补发报警信号。

公共自动复位适用于五项检测报警、系统控制器断连、相机断连、旧版纠偏器断连、MES 断连和采集处理帧差的 PLC 输出地址，以及规格牌 PLC 输出和人工复位命令。主 PLC 断连、存图积压及运行提示不输出 PLC，不受此设置控制；数据交互中的读取、心跳、状态及实时结果地址和独立声光输出也不受控制。定时复位仅将 PLC 输出写回 0，不清空报警计数、不解除故障、不恢复检测，也不关闭报警弹窗。

人工报警复位

点击“报警复位”后需二次确认；取消不执行操作。确认后只清空本模块的规格牌及五项报警计数，不清产量、米数、瑕疵统计、相机帧数或过程能力数据，也不会把真实故障标记为正常或恢复检测。

页首公共参数可配置人工复位命令地址与 bool、int、float 类型，命令固定写入 1，并使用共用保持时间。地址未配置时仍可清理计数。软件分别提示计数清理和命令结果，PLC 写入成功不代表设备故障已经解除；内部换料号清理不发送此人工命令。

配置规格牌规则

  1. 在“报警设置 → 规格牌”选择尺寸报警或瑕疵报警，新增规则。
  2. 尺寸规则选择尺寸名称、标准值、上下限、检测次数和 NG 次数；瑕疵规则选择类别、适用范围及命中条件。
  3. 按需要设置弹窗、声光和写入 PLC，并核对 PLC 地址；写入信号后是否停机，由设备程序决定。规格牌喷码项目前仅记录日志，不实际发送。
  4. 保存规则；需要批量复用时使用导入或导出，导入后重新检查名称与适用范围。

规格牌按滑动窗口判断：例如检测次数为 10 时，未触发会按 1～10、2～11、3～12 窗口继续判断，触发后清空该规则重新计数。瑕疵按次数计数时，一次命中多个仍只算一次；按个数则累计实际瑕疵数。

独立统计时，各 ROI 分别判断，某个 ROI 触发只清空该 ROI 的规则计数。条件为空表示存在对应瑕疵即命中；表达式使用长度、宽度、面积、长度/宽度、宽度/长度和比较、且/与/&&、或/||、括号组合，单位为 mm 和 mm²，长宽比无单位。长宽比的分母为 0 或无效值时条件不命中。

瑕疵区域按“相机名称＋区域名称”匹配，名称由配置人员保证唯一。调整区域名称后，应重新核对规格牌范围和喷码区域映射；历史数字区域编号不再参与匹配。

“写入 PLC”沿用“详细报警”页首公共参数中的自动复位与保持时间，不为每条规格牌规则单独设置。默认关闭自动复位；开启后，例如保持 100 毫秒，在首次成功写入 1 后的第 80 毫秒再次触发同一地址，仍在首次计时约第 100 毫秒写入 0，不延后到第 180 毫秒。不同地址独立计时，详见PLC 报警保持时间。声光输出使用独立保持逻辑，不受此 PLC 参数控制。

详细报警怎样配置

先设置顶部常用检测报警，再按需启用设备与采集监控。每行直接显示触发处理，悬停可查看适用条件。PLC 地址留空时不发送事件信号，系统控制器和相机断连的停止检测处理仍按配置执行。

项目触发条件与处理
主 PLC 断连数据交互启用后检查主 PLC 状态，断连时显示报警窗口；不停止检测。
系统控制器断连控制器和数据交互启用且正在检测时检查，断连后显示报警窗口、按配置写 PLC，并停止检测。
相机断连逐台检查相机可用状态，断连后显示错误通知、按配置写 PLC，并停止检测。
旧版纠偏器断连仅旧版纠偏链路有效，断连后显示报警窗口、按配置写 PLC，并按原流程检查重连；该开关还监测系统控制器的纠偏伺服报警。
MES 断连按 MES 通道分别跟踪，显示报警窗口并按配置写 PLC，不停止检测，自动重连继续执行。
采集处理帧差每台相机输入帧数减去结果输出帧数，严格大于阈值时显示报警窗口并按配置写 PLC；不停止检测。帧差也可能来自处理积压，不等于已经确认丢帧。
大图存图积压大图队列达到 20 项时在报警窗口提示，同类提示至少间隔 60 秒；不写 PLC、不停止检测。小图积压仅记日志，关闭提示不关闭队列保护。

上述断连和帧差事件按监控对象跟踪，同一次持续异常只通知一次，恢复后再次异常可重新触发。报警窗口为独立的消息窗口，不要求逐条确认。

开检与运行提示的区别

  • 开检前确认：开始检测前弹出需要确认的窗口，取消则本次不开检；可编辑确认内容，不写 PLC。
  • 旧版纠偏未发送提示：旧版纠偏计算结果未发送时显示报警窗口，包括超出上限、低于发送下限等结果；该提示本身不写 PLC、不停止检测。采用新版纠偏时不依赖此开关。
  • 自动关灯提示：仅用于“有图开灯、无图关灯”的自动光源流程；首路输入帧数连续约 10 分钟没有增加时执行关灯并显示报警窗口。它不监测意外关灯，也不代表已经读取到光源关闭反馈；不写 PLC、不停止检测。

这些开关都有运行调用。使用新版纠偏或未启用自动光源流程时，可不勾选相应的旧版、自动关灯提示；关闭提示不替代设备故障处理。

报警弹窗外观与预览

页底按三组调整报警弹窗：位置与尺寸配置坐标及宽高，文字与颜色配置字号及背景色，显示与预览配置自动隐藏时间和显示条数上限。自动隐藏设为 0 时保持显示；消息只保留最近若干条，实际至少保留 10 条。“预览报警弹窗”用于查看当前设置，修改后仍需点击“保存详细报警”。隐藏弹窗不等于报警复位，也不改变 PLC 输出状态。

独立喷码配置

入口为“报警设置 → 喷码机设置”，也可从主页顶部“检测 → 喷码机设置”打开弹窗。弹窗与页签使用同一套配置控件并共享编辑草稿，可同时查看和操作；输入、勾选、机型及映射修改即时双向同步，不依赖保存或重新读取。重复点击菜单会激活已有弹窗；关闭后重新打开仍保留未保存的草稿。仅支持依玛士 NG16 结果式和多米诺 ASCII 坐标协议，依玛士固定 16 个喷头。两种机型分别保存各自的连接参数、发送规则和料号映射，切换机型不会覆盖另一机型的设置。全部喷码设置独立保存在应用目录的 Config\InkjetPrinterConfig.json；设备参数随本机保存，区域、瑕疵编码、尺寸映射和自定义上下限按料号保存。

  1. 在“设备连接”选择类型，填写 IP、端口、连接超时；多米诺另设应答超时。超时单位为毫秒，范围 100～60000。“测试 TCP 连接”只检查网络连接，不输出 IO，也不代表设备已喷印。
  2. 在“触发与发送规则”选择每帧触发相机，填写 IO 输出点位和脉冲时长，选择 A/B 面宽度、瑕疵和错位开关。脉冲时长为 1～90 毫秒，触发相机必须存在。
  3. 在依玛士“区域喷头”或多米诺“区域参与喷码”核对当前料号。表格自动列出全部相机及其区域，第一列为“启用”，第二列为相机名称，无需切换相机。新增区域默认勾选；取消勾选后该区域不发送。依玛士固定 16 个喷头（协议称“喷印区间”），每个区域通过多选下拉框选择一个或多个喷头；多米诺按坐标发送，不使用喷头配置。按区域名称维护，不再在瑕疵参数页填写数字编号。
  4. 在“瑕疵编码”配置每类瑕疵的独立编码。依玛士为两位十六进制 04～FF，多米诺为小写字母 a～z；此编码与 MES 编码分开保存。依玛士优先级数值越小越优先，多米诺不使用此优先级。
  5. 在“尺寸与错位”维护名称、面别和编码；依玛士用多选下拉框配置 1～16 喷头，尺寸结果发送到该行所选的全部喷头，宽度编码默认 40、错位默认 16。多米诺默认编码分别为 j、k。需要单独的喷码判定范围时，在“喷码上下限”填写绝对测量值，单位 mm。
  6. 瑕疵、尺寸和错位表也可按行启停，新增行默认启用。“开启喷码”为绿色按钮，“关闭喷码”为红色按钮，点击会立即保存当前配置并切换喷码状态；开启前先完成必要参数和映射。仅修改参数时点击“保存喷码配置”。保存成功后按配置连接并使用新参数；未保存的编辑会在两个入口同步显示，但不影响运行；料号切换后两个入口同步显示新料号；“重新读取”会同时放弃两处未保存修改。

“宽度连续NG次数”“错位连续NG次数”按面别和类型计数，达到设置次数时发送并重新计数。取消顶部 A/B 宽度、A/B 瑕疵、错位、仅碳膜和 B 面镜像开关，只按区域、瑕疵编码及尺寸表逐行启用。依玛士每个结果报文只发送一次；镜像由喷码机处理，视觉软件不反转喷头编号。

依玛士按所选喷头编号升序，将区域横向宽度从左到右等分；瑕疵包围框与哪个区间交叠，就发送到对应喷头，跨区间发送多个。例如选 3、4、5，则分成三段，瑕疵跨前两段时发送到 3 和 4。恰好贴住分界的包围框不额外命中相邻区间；零宽度点落在分界时归右侧区间。区域外或无效坐标跳过并记录日志。

仅同帧、同面、同喷头、同 5 mm 偏移区间的结果发生冲突时合并，瑕疵优先级数值越小越优先；瑕疵优先于尺寸，同优先级保留先到项。其它喷头和偏移的结果均保留，不再因整面存在瑕疵而屏蔽尺寸。页面右侧按机型显示报文格式、发送顺序和示例。

最近发送

“开启喷码”保持绿色，开启后显示红色“关闭喷码”，悬浮时保持对应颜色。“最近发送”表格只保留本次运行最近 200 次发送尝试，不保存到磁盘；按时间倒序显示发送摘要与报文预览，选中后可在下方查看、复制完整报文。依玛士报文显示十六进制，多米诺显示 ASCII；同一条报文的应答结果更新到原记录，TCP 写入成功不代表设备已执行喷码。

首次迁移与异常恢复

第一次没有独立配置时，软件自动逐项迁移历史设置并保存，不再设置迁移记录页或人工确认步骤。旧类型 100、200 分别对应多米诺和依玛士，其余类型不支持。旧区域数字编号和旧瑕疵 Code 不迁移到新映射，也不改动 MES 编码；缺失项可在当前页面直接补配。

首次迁移的必要项无效时保存为停用状态并记录原因。旧版独立配置的区域编号 1～8 自动转换为原来对应的两个喷头，例如 1 转为 1、2，8 转为 15、16；尺寸输出槽转换为喷头列表。最早版本的空区域编号转为未配置，须补齐后开启。升级保留原文件备份，取消旧顶部筛选和软件镜像，现场应核对逐行启用与喷头方向。独立配置损坏或缺失时喷码停用，原文件保留，可在页面重新配置并保存；故障恢复保存会保留原文件备份。配置加载异常和触发相机缺失不在启动时弹窗，喷码设置页显示简要原因，详细错误记录在 Error 日志。运行时禁止回退使用旧 SystemInfo 值。当前料号映射不完整或触发相机不存在时停止发送。软件运行中可反复开启、关闭喷码；关闭时断开连接、中断应答等待并作废待发送数据，再次开启按原连接周期重连，不补发关闭前的数据。开检、停检、换料号和保存新配置也会作废待发送的旧帧。

发送状态与排查

连接、入队、IO、发送、应答、失败和重连记录保存在软件日志，相关记录带“喷码”字样，发送记录统一带“【喷码】”；页面不再单设诊断页签。排查时先确认页面状态与料号，再检查触发相机、区域和编码映射，随后检查 IP、端口、IO 控制器及设备应答。

状态含义
已入队报文已进入发送队列，尚不能证明网络写入。
TCP已写入网络写入完成，不能作为实际喷印成功的依据；依玛士当前协议无逐包确认。
设备已确认多米诺返回完整小写 ok；仍需结合设备状态确认实际喷印。
发送失败连接、IO、异常应答或超时失败，记录原始报文和原因，断开后按原流程重连；失败数据不补发，检测继续。

依玛士先计算每个瑕疵对应喷头和偏移，再逐喷头合并冲突并记录取舍；不同位置的瑕疵不会提前丢弃。同帧结果等待触发 IO 和 ID 后发送。排队超出触发时限或等待同帧触发超时的数据会丢弃并记录，避免过期喷码。多米诺每帧输出 IO 后发送 ASCII 坐标，未返回完整 ok、异常应答和应答超时均判定失败。

规格牌的弹窗、声光和 PLC 输出共享该规则计数，触发后按勾选项分别执行；规格牌喷码项目前仅记录日志，不实际发送。画面弹出报警不能单独证明 PLC 已接收，需检查对应输出和设备实际状态。
