光源控制

通过“工具”中的光源控制入口打开配置，核对控制器通信方式、通道和对应相机，先测试连接，再启用需要的通道。

光源控制提供三台控制器，每台两路。各路可以选择相机和区域，设置目标灰度及公差。调整后观察图像亮度和区域选择，避免只凭整图观感判断测量区域的照明。

保存与自动校验

点击保存统一提交控制器草稿。换卷自动校验使用已保存配置，当前输入尚未保存时不会代替正式参数。

采集触发与门控

先检查相机自身触发模式和设备信号。部分项目提供正运动采集门控、分时频闪或多重曝光，这些功能按项目接线和控制器程序配置。

正运动门控开关只控制相关 TABLE 和 OUT7 写入，不代替相机启停；切换前先停止采集并确认设备状态。门控、频闪与自动取流是不同功能，应分别核对。

PHDL-X2 分时频闪控制器

PHDL-X2 使用带组合号的独立协议，请在型号中选择“PHDL-X2”，不要选择普通“Wordop”。每台仍提供光源1、光源2两路操作，在高级设置中分别填写组合号1～8及物理光源通道1～4。组合号、通道号均从1开始，两路不能指向同一组合的同一通道；可以按接线选择不同组合或通道。

高级设置提供常亮模式、频闪模式及频闪触发方式。打开窗口先显示软件保存值；“测试连接”读取硬件实际TR并回填：TR=15为常亮，TR=2、3、7为频闪，分别对应外部下降沿、外部上升沿、内部触发。常亮时保留软件记录的频闪方式，未记录默认外部上升沿。测试连接、界面选择及保存配置均不会写入TR，也不修改触发输出、频率或延迟。需要改变硬件模式时，请先在控制器或厂家Demo设置，关闭Demo释放通信资源，再测试连接同步。两路全部回读成功才显示通信正常。

频闪模式手动加减和自适应调整发光时间T，显示值、时间上下限及时间步长单位为0.1μs，范围0～1000，例如154表示15.4μs。常亮模式调整映射通道的亮度等级L，范围0～100。切换型号、模式、映射或通信端点后需要重新测试连接；软件不自动换算现场上下限，须按回填模式核对后保存。自适应仍使用涂布现有有效帧和ROI采样方式，不按控制器组合号筛选图像，需确认所选ROI对应配置组合的照明图像。

自动开关只控制两路已配置映射。频闪开灯写L=1、关灯写L=0，保留T、F及TR。常亮关灯前记录每路L，关灯写0，开灯恢复；重复关灯不会覆盖已记录的恢复值。恢复值仅保留本次软件会话，重启后若设备为0且无记录，会明确提示恢复值未知，需先设置控制器亮度。操作后均回读确认，部分失败时不能认为全部光源状态已确认。三台控制器按各自实际串口或UDP端点独立统计成功开关后的使用时长。

“保存配置”保存软件的型号、映射及调节参数，不会自动保存控制器的断电记忆。临时调光和自动开关也不自动执行控制器参数保存；如需保留设备参数，请按厂家控制器操作要求保存。

PHDL-X2 UDP网口

PHDL-X2可选择串口或网口；Wordop和CSTIPC继续使用串口。网口只填写控制器IPv4地址，两端UDP端口固定1200，本机IP由系统路由选择，不提供TCP、端口编辑、广播发现或自动修改网卡参数。同一控制器IP不可重复，串口方式下COM口不可重复；切换通信方式会保留已填写的另一种参数。

先在厂家Demo将控制器设为UDP，并将PC IP设为本机通往控制器的网卡地址，两端端口设为1200，然后关闭Demo释放端口。连接失败时先核对IP、路由、设备UDP模式及端口占用；超时提示会显示软件选用的本机IP。多台控制器共用本机1200端口，软件按顺序通信，不自动重发超时命令。

亮度与自适应操作

  1. 打开“工具 → 光源控制”，选择控制器页签，核对通信端点和两路光源。
  2. 先测试连接，读取亮度后检查每路对应的物理光源。
  3. 需要自适应的光源选择所属相机与 ROI，再填写目标灰度、允许公差和亮度范围。
  4. 用“立即测试”检查当前控制器，或用“校验全部”顺序检查已启用的光源；观察灰度、进度和错误。
  5. 完成后“保存配置”，统一提交三台控制器及公共策略。

未使用的控制器保持禁用；禁用保留参数，但禁用本身不发送关灯命令。同一COM口或UDP控制器IP不允许重复。调节任务执行时不能切换控制器或修改参数。连接确认且已启用时，运行中加减仍可点击，会弹窗提示先停止系统，不发送手动调光命令；停机后每次加减1。连接、保存及测试条件失败会在状态区、日志及主题弹窗提示。

采样、停止和换卷校验

自适应单次步长：PHDL-X2为1～1000，Wordop和CSTIPC为1～30。实际调整仍受现场上下限、最大次数、灰度响应方向及振荡保护约束；常亮最大L为100，步长不会突破其上下限。手动加减固定为1，不使用自适应步长。

自适应采样先跳过指定张数的新有效图，再连续取样平均；图像中断会超时结束。停止操作会取消当前及后续待执行光源，单路失败会保留该路原因，不能把其他光源成功当成全部成功。

手动测试使用当前页面草稿，换卷自动校验使用已保存配置。“Run Open, Stop Close”和有图／无图开关策略按所选模式执行，检查时要同时观察运行状态和图像来源。

亮度不对或自适应失败

  1. 确认控制器、串口或UDP端点、通道和物理光源一一对应，避免调节另一面的光源。
  2. 检查选中相机及取样区域是否位于真实材料内，区域错误会让目标灰度失去意义。
  3. 确认有持续新图；自动停流或触发中断会让采样等待、超时。
  4. 观察允许亮度范围和目标灰度，达到亮度边界仍不满足时检查照明、曝光与材料条件。
  5. 查看本路失败原因，再核对其他路；保存后确认换卷使用的是正式配置。

光源连接、调节完成与图像达到目标灰度需要分别确认。不要同时大幅调整曝光、亮度与检测阈值，否则难以比较是哪一步改善了效果。

光源通信日志

Debug日志中的“【光源通信】”记录型号、串口及波特率或UDP端点和报文。TX表示发送请求，RX表示接收结果，ERROR表示通信错误。普通Wordop的SDK调用记录请求及最终返回，内部重试仍由SDK执行；CSTIPC和PHDL-X2同样记录通信报文。

连接失败时，结合对应通信端点的TX、RX和ERROR核对原因：有设备错误码时检查命令和参数，有超时或不完整回包时检查串口占用、接线及通信参数，有组合字段时检查是否选择PHDL-X2及正确映射。界面“未连接”表示参数回读未全部确认，不单指串口打不开。
