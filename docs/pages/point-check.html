选择正确的点检功能

“直线工具 → 点检工具”提供当前项目的尺寸或标准块检查；“功能 → 点检设置”提供标准片圆点和双圆标检查。它们的区域、规格和保存入口不同，不应混用参数。

标准块与尺寸点检

  1. 进入点检工具并选择相机，抓取或加载标准样图像。
  2. 点击“检测区域”，检查区域确实覆盖待测标准样。
  3. 核对点检尺寸或标准参数，执行“单次点检”，查看尺寸、结果和失败原因。
  4. 需要循环检查时，确认单次检查完成后启动循环；切换或关闭前先停止循环。
  5. 按相机设置启用状态与 CSV 目录，点击保存。

图像缺失、区域无效和实际测量超差应分别处理。更换料号后重新打开配置核对当前上下文，不沿用错误料号的检查结果。

标准片圆点与双圆标

  1. 在“功能 → 点检设置”选择相机和点检方式，加载图像。
  2. 添加 ROI，设置圆点灰度、像素面积和最小圆度；标准片方式还需检查贴片灰度、面积及矩形度。
  3. 标准片填写圆点直径规格和上下公差；双圆标填写标准圆心距离及允许偏差。
  4. 点击“离线检测”检查显示结果和原因，调整后重新检测。
  5. 设置 CSV 目录，按需要启用在线与定时检查，最后保存参数。

圆点提取面积单位是像素，直径、距离和公差单位是 mm。灰度范围为 0～255，最小值不能大于最大值。

定时与超时停机

定时配置使用 HH:mm 时间、间隔天数和超时分钟；按需要勾选“超时停机”。页面会显示当前检查与计划状态，保存后核对。

离线检测用于检查本地图像和当前参数，不代表实际在线采图正常；计划完成状态需结合下文的测量结果说明核对。出现超时或不通过时，先查看状态原因、标准样图像、时间配置和 CSV 保存结果。

“已完成”与“合格”分别确认

圆点点检的定时完成状态与测量判定分开。当前计划有效期间，只要形成可测量的点检结果，就可能记录该计划已完成；结果是否合格仍需查看直径、圆心距离和判定，不能只看“本次定时点检已完成”。

离线检测也会记录结果和 CSV；满足当前计划条件时可以更新完成状态，但不能据此证明真实在线采图链路正常。在线检查使用已保存配置，修改 ROI 后应保存再观察在线结果。

点检失败与超时检查

现象处理顺序
目标提取不到核对点检方式、相机、ROI、灰度范围和像素面积；标准片同时检查贴片条件。
能测量但判定 NG核对标准样实际规格、公差和当前相机标定，不只放宽像素提取范围。
“定时配置无效，点检时间格式应为HH:mm”检查时间格式、间隔天数和超时分钟，再保存。
“点检已超时，但PLC未连接或停机地址未配置”检查 PLC 连接和停机地址，不能把提醒当作已发送停机命令。
CSV 保存失败核对目录、权限和磁盘；保存文件失败与测量是否完成分别判断。
