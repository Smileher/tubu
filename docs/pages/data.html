结果与文件保存

尺寸、瑕疵、统计、原图和数据库保存分别受各自开关、路径及触发条件控制。在配置中确认需要的保存类型，使用软件相应的文件查看入口核对实际文件。

页面显示结果、任务已入队和文件成功写入是不同阶段。文件缺失时先检查保存开关、路径模板、当前料号与膜卷、磁盘可写性和错误日志。主页临时存图与检测 OK／NG 图保存彼此独立。

换卷输出以旧卷快照为依据，后台保存可能晚于主页新卷号更新。检查统计文件时，应核对文件归属和换卷时间，不用新卷号查找上一卷报表。

查找结果

“数据”菜单提供尺寸数据目录、瑕疵数据目录和图像目录入口。“数据 → 数据查询”可进入已配置的数据查询功能。先确认日期、料号和膜卷，再查找对应结果。

主界面统计展示与落盘输出分别受配置控制。数据不一致时记录查询条件和故障时间，先核对是否属于同一相机、同一卷和同一统计范围。

设置保存类型

在“系统设置 → 文件保存”中选择需要的保存项并核对路径。尺寸过程数据、瑕疵过程数据、原图及相关统计分别设置；修改后使用当前页面保存入口。

尺寸 NG 大图的“连续上限”用于限制连续 NG 期间的存图，不是后台存图队列容量。计数由符合尺寸 NG 存图条件的相机共用，尺寸与错位综合结果为 OK 时清零；当前规则在计数达到上限时即跳过本次保存，因此允许入队的图片数可能少于所设上限。日志“尺寸NG大图已按连续上限设置跳过保存”只表示该相机本次尺寸 NG 大图未入队，不表示检测结果处理停止。

查询历史检测数据

  1. 通过“数据 → 数据查询”打开窗口，选择要查询的数据库。
  2. 选择尺寸、错位或瑕疵类型，设置起止日期；开始时间不能晚于结束时间。
  3. 按需要填写料号、膜卷号、判定、检测项、面别、相机及瑕疵名称等条件。
  4. 点击“查询”，等待结果后查看记录总数，使用分页查看其余记录。
  5. 修改条件后重新查询；需要重新选择时使用“重置”。

查询的是所选数据库中已保存的记录，不是实时画面的所有数据。没有记录时先检查数据库选择、时间范围和保存开关，再逐步减少筛选条件。

导出 CSV 与查看关联图像

“导出 CSV”按最近一次成功查询的条件导出全部匹配记录，不只导出当前页。修改输入条件但未再次查询，不会改变这次导出的条件。导出前先确认当前查询结果。

记录包含图像路径时可查看关联图像；没有路径、文件已清理或磁盘不可访问时，先查看提示。查到检测记录不代表一定保存过对应原图。

保存路径与文件归属

在“系统设置 → 文件保存”分别核对尺寸、错位、瑕疵、图像和统计保存项。带动态字段的路径按当前检测上下文生成；检查实际文件时，核对日期、料号、卷号、面别和相机，不能只看一个固定目录。

需要追溯原图时，同时开启对应图像保存类型，并检查保存条件。存图数量、格式和压缩设置应结合磁盘余量调整；自动清理会按配置清理历史文件。

界面有结果却找不到文件

  1. 确认实际启用的是所需保存类型，检查是否只保存 OK、NG 或局部图。
  2. 从“数据”菜单打开实际保存位置，核对当前卷和上一卷的日期目录。
  3. 确认磁盘空间、路径写入权限和网络路径可用性。
  4. 查看同一时间的保存错误、后台任务和自动清理记录。

CSV、数据库、统计报表和原图各有独立保存条件。应逐项核对，不用其中一项成功推断所有类型都已保存。

过程 CSV 表头与字段

在系统设置中分别开启尺寸／瑕疵 CSV 保存，并检查对应路径。输出语言从“基本参数”独立选择，详见输出语言。非简体中文时，外文和中文位于同一单元格；含逗号、引号或换行的字段按 CSV 规则加引号。字段自身换行仍属于同一条记录，建议使用支持标准 CSV 的工具打开。

尺寸及错位测量值、标准值、公差偏差、补偿值的单位均为 mm。“上偏差／下偏差”保留原公差偏差数值，不代表标准值加公差后的绝对规格上限／下限；标准值、公差及补偿列仍由各自保存开关控制。英文采用 Std、Upper Dev、Lower Dev、Comp 等短表头。

部分工艺的瑕疵过程输出使用原有汇总结构，只调整固定字段表头，保留自定义名称和计数，不追加明细长宽列。已有 CSV 不迁移或修复；调整输出语言、外文名称或保存列后，需要新文件才能取得完整的新表头。

查不到记录的逐项检查

检查项正常表现与下一步
数据库已选择实际保存检测结果的 .db 文件；不是只选了一个同名目录或旧备份。
时间范围开始不晚于结束，覆盖实际检测时间；跨天时扩大日期范围再试。
类型与条件选择尺寸、错位或瑕疵中的正确类型；暂时减少卷号、相机、判定等筛选确认范围。
保存来源当时已开启对应数据库保存，且未发生写入错误；实时结果不会因事后开启保存而补入历史库。
图像关联记录含有效路径且文件仍存在；“当前瑕疵记录没有可查看的图像。”不表示该条检测记录不存在。

出现“查询数据库失败：”或“导出失败：”时，保留冒号后的完整原因和当前条件。排查期间先备份原始数据库，不用覆盖配置或清空记录解决查询问题。
