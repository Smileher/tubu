标定与标零分别做什么

标定建立图像像素与实际毫米的对应关系；标零确定测量位置参考。入口为“系统设置 → 相机管理 → 标定”。选择与实际相机、幅面和安装条件一致的标定图，核对标准黑条及白区的真实尺寸。

完整操作顺序

  1. 选择当前相机，点击“加载标定图”。
  2. 填写边缘模式、灰度阈值、黑条宽度和白区宽度，点击“添加/定位 ROI”，使区域覆盖有效条纹。
  3. 点击“执行标定”，查看检测状态、平均精度、有效分区及分区明细。
  4. 需要指定标零位置时，点击“添加标零直线”，左右拖动垂直线，填写该线对应的实际位置，单位为毫米。
  5. 核对像素位置与实际位置；标零线可在整张图像的横向范围内移动，不再执行标零抓边。
  6. 点击“保存标定/标零结果”，确认成功提示，再用已知尺寸检查测量。

每台相机最多配置一条标零直线。“删除标零直线”只修改当前页面草稿，点击保存后才生效。没有标零配置时，软件使用图像左端 X=0、实际位置 0 mm 作为默认线，默认线不写入配置；无标零配置不阻止启动检测，相机仍须具有有效标定。

旧标零配置沿用已保存的像素位置和实际位置，显示为垂直直线。多相机料号创建引导仍需有效标零直线校验实际拼接关系；默认左端线不能替代这项校验。未关联相机可不单独配置标零。

检查结果与合理性提醒

平均精度只概括整体比例，还应检查局部精度曲线、分区像素宽度、条纹歪斜和异常原因。出现质量提醒时，先检查图像质量、ROI 和真实条纹尺寸，不仅比较平均值。

页面的“标定时间”优先显示当前标定图的文件创建日期；图片不存在或日期无法读取时显示原记录时间，均无记录时显示“未记录”。实际执行时间与历史记录仍按标定执行时刻保存。

没有有效分区、无有效边缘或结果无效时不能保存。部分合理性提醒允许保存和使用，但应先确认提醒的实际原因。

换图后必须重新执行

更换标定图后，需要在新图上重新完成标定，并核对手动标零线位置；切换相机不会绕过重新标定的要求。本次标定执行失败时不能套用旧结果保存，按提示修正后重新执行。

“使用像素标定值计算（不叠加补偿）”会改变尺寸与错位最终计算是否叠加人工补偿，界面提示保存系统设置后重启生效。使用前应确认计算方式符合当前测量要求。

导出与问题检查

“导出标定图”保存 BMP 副本，不能覆盖软件已保存的标定图；“导出 CSV”用于保存当前相机标定结果。导出文件不等于提交了新的标定配置。

抓不到边时，依次检查图像、ROI、灰度阈值、极性和搜索方向；换相机或调整安装后不要只修改补偿值代替重新核对标定。

标定参数与结果检查

项目含义与检查重点
黑条宽度、白区宽度填写标准样的真实尺寸，单位按页面毫米值；错误标准尺寸会带来整体比例误差。
灰度阈值、边缘模式用于从当前图中区分条纹和边缘；先检查条纹清晰程度，再调阈值。
标定 ROI覆盖有效条纹，避免图像边界、污损和无关背景；无有效分区不能保存。
标零直线、像素与实际位置垂直线的横向像素位置对应填写的毫米坐标；支持整张图像范围。默认左端线对应 0 mm，换算保持标定范围内的分区精度。
平均精度与分区明细同时检查整体比例和局部变化。平均值接近预期，不能代替分区质量检查。

提示“未提取到有效分区”时，先确认 ROI 覆盖标定膜黑条；提示“当前相机标定数据无效，请重新标定”时，重新执行并保存当前相机的有效标定，不复制其他相机的数值。

保存之后怎样确认

  1. 确认当前相机、本次图像上的标定成功，手动标零线或默认左端坐标符合要求，且保存成功。
  2. 回到尺寸检查，用已知尺寸核对不同横向位置，避免只用一个位置判断整个幅面。
  3. 检查人工补偿是否参与当前计算模式，再比较显示值和实际尺寸。
  4. 保留本次标定图和 CSV，便于在更换相机、镜头或调整安装后对照。
