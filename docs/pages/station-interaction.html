连接与保存

在“数据交互 → 工位数据交互”设置交互工具 IP、端口及启用状态。选择是否发送尺寸错位、发送瑕疵，以及主程序启动时是否自动启动交互工具。

  1. 确认交互工具正在目标地址运行，检查网络与端口。
  2. 按实际工位选择发送项目，不发送无对应关系的数据。
  3. 保存后检查连接状态，再核对本机与接收端的同一批测量数据。
  4. 需要查看工具时使用“打开交互工具”。

连接参数和启用状态保存即可应用。网络始终传输原始检测数据，各 CCD 按自己的反转配置生成本机运行数据。

尺寸和错位顺序反转

按 A 湿、B 湿、A 干、B 干或对应错位组选择顺序反转。普通反转后，名称、Code、测量值、标准值及上下限仍跟随原测量对象。

例如尺寸1/50、尺寸2/30，反转后显示为尺寸2/30、尺寸1/50。总膜宽、点检尺寸和未启用尺寸不参与尺寸反转。该设置同时用于本机自产数据和交互接收数据。

同时反转名称和 Code

“反转后同时反转尺寸 Name 和 Code”会重新标识已反转的数据，不只是换显示顺序。上述示例会成为尺寸1/30、尺寸2/50。

启用前必须检查 MES、公式、虚拟图和动态补偿中按名称或 Code 建立的映射；不确定映射时保持此项关闭，先核对普通顺序反转是否已满足要求。

数据不一致时

比较同一卷、相同工位和数据集中的原始值、名称、Code 与显示顺序，再检查两侧反转设置。通信成功但数据含义不一致时，应先修正映射，不能只通过重复连接处理。

建立一次可靠的数据对应

  1. 选定同一卷和同一数据集，记录发送端某一尺寸的名称、Code 和测量值。
  2. 在接收端找到同一对象，先确认原始传输，再检查本机反转后的显示顺序。
  3. 普通反转只变顺序；同时反转名称和 Code 则会改变测量值对应的标识。按需要选择，不能混为一项。
  4. 如果这些值参与虚拟图、公式、MES 或动态补偿，逐项核对引用对象，最后保存并检查实际数据。

出现“交互工具 IP 地址格式不正确。”或“交互工具端口必须在 1 到 65535 之间。”时，先修正连接参数。能打开工具窗口只说明工具已启动，仍要确认连接与本次数据。
