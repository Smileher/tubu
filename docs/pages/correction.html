新版纠偏设置

启用新版纠偏后，通过“检测 → 纠偏闭环设置”进入窗口。基础页配置偏移公式、偏移范围、单次最大量、平均笔数、发送后跳过笔数和最低速度；公式可使用已有测量尺寸和四则运算。

窗口顶部“启用纠偏功能”与自动纠偏开关分开控制。停止检测并等待发送结束后，勾选或取消“启用纠偏功能”，点击“保存并应用”生效。未启用时，底部“纠偏”状态隐藏，自动纠偏、手动微调和设备故障复位不可用；启用后显示设备状态，自动纠偏仍需单独开启。仅关闭自动纠偏不会隐藏设备状态，也不会切换纠偏版本。

首次未配置过新版纠偏时，功能默认不启用；已有新版配置缺少功能开关时保留启用。重新启动软件后，自动纠偏仍默认暂停。

高级页配置数据过滤、纠偏设备和设备联锁。PLC 纠偏量点位支持“地址|int”或“地址|float”，如 D1004|float。float 使用 mm；int 为 32 位整数，将 mm 乘 100 后向零截断，超出范围时暂停发送。类型后缀优先于勾选项；不带后缀时默认 FLOAT，勾选“无类型后缀时按INT×100发送”则使用 INT×100。纠偏量需要保留正负方向，不使用 BOOL。专用纠偏设备按所选类型配置通信参数。

许可与完成点位支持 int、bool、float，如 D1002|float，不带后缀时保持 BOOL。BOOL 的 TRUE 或数值非 0 表示信号有效，0 表示无效；读取失败或浮点数无效时暂停发送。软件发送完成后按该点位类型写 1，等待 PLC 写回 0。

类型必须与 PLC 程序一致。int 与 float 均占 4 字节；按 PLC 的实际地址规则预留空间，避免完成信号与纠偏量等相邻点位重叠。bool 使用 PLC 驱动支持的位地址。不支持的地址或类型组合会报错，不会自动更换类型。

点击“保存并应用”提交配置。切换实际发送设备要求停止检测且没有发送任务。未保存的设备选择不会改变后台发送目标。

自动纠偏的运行过程

顶部快捷栏的“启用纠偏／停止纠偏”按钮与纠偏设置窗口控制同一个自动纠偏开关。按钮显示“停止纠偏”时表示自动纠偏开关已开启，仍需满足速度、采样、许可及设备条件才会发送；故障暂停时先处理窗口提示。快捷操作仍受数据发送权限和原有操作条件限制，不改变纠偏功能启用配置。

  1. 开启自动纠偏后检查速度、测量结果、许可和设备状态。
  2. 按配置收集样本；低于最低速度或速度无效时清空采样并等待恢复，等于最低速度允许采样。
  3. 按偏移公式和过滤条件计算纠偏量；死区、超限或有效样本不足时不发送。
  4. 发送成功后按配置跳过若干笔；配置完成点位时写 TRUE，并等待 PLC 清零后再继续。

默认处于暂停状态。暂停后再开启、换卷或停止检测会清空采样。通信失败、发送结果不确定或纠偏 CSV 保存失败时会暂停后续发送，先核对提示和记录，避免重复动作。

完成点位表示软件数据发送完成，不表示纠偏机构已完成机械动作。许可点位留空则不限制，完成点位留空则不等待清零。使用联锁时要同时核对 PLC 逻辑。

手动微调与初始化

纠偏设置窗口提供手动微调，步长为 0.1～5 mm，精度 0.1 mm。自动纠偏开启时手动按钮禁用。一次发送结束后至少等待 1 秒；配置完成点位时，还须等待 PLC 清零。

“初始化”清空软件采样、跳过计数和暂停原因，下一次重新检查和初始化设备。它不会改变自动纠偏开关，不代替 PLC 清零，也不会重发旧纠偏量。

关闭设置窗口不会停止后台自动纠偏。有未保存修改时可选择保存、放弃或取消；放弃仅丢弃界面编辑，后台继续使用原已保存配置。

系统控制器相关纠偏点位

系统控制器的纠偏使能、故障复位、限位故障及左右移动信号支持“地址|int”“地址|bool”“地址|float”。控制信号写入 1 或 0，不应用纠偏量倍率；故障信号为 TRUE 或非 0 时表示故障。读取失败不会当作故障已解除。

裸地址保留原入口的默认类型：纠偏使能与主页复位为 bool，新版设备故障复位为 int，旧数据交互复位与左右移动为 float；限位提示读取为 bool，旧纠偏伺服报警监测为 float。同一复位或故障点位可能被不同入口使用，建议明确填写类型后缀，并与 PLC 程序一致。

旧版闭环位置读取与延时写入可指定 int 或 float，裸地址分别沿用 float 和 int；位置不额外缩放，延时保留原站点数值和单位。旧版纠偏量仍按原料号类型及站点倍率发送，不使用新版的 INT×100 规则替换。

没有发送或设备没有动作

  • 先读窗口顶部运行提示，区分未开启、低速、死区、超限、样本不足、许可不满足和通信失败。
  • 确认选中的设备已连接，PLC 量输出点位、单位和联锁点位与现场一致。
  • 完成点位一直未清零时，先检查 PLC 是否已接收并执行复位逻辑，不连续点击手动发送。
  • 软件显示发送成功而机构不动时，继续检查 PLC 数值、许可、设备模式和机械状态，不能直接判定软件重复发送即可恢复。

配置采样与偏移范围

先通过“添加尺寸”选择实际参与计算的数据，再填写和校验偏移公式。平均笔数决定一个独立采样批次，发送后跳过笔数用于等待材料或设备响应，最低纠偏速度用于排除低速过程。

偏移绝对值不超过下限时不发，超过上限时也不发；单次最大纠偏量则限制一次实际发送幅度并保留方向。它们分别用于死区、异常保护和单次动作约束，不应当作同一个参数。

启用异常数据过滤时，按与批次中位数的偏差剔除样本；测量失败始终排除。过滤后达不到至少有效笔数时不发送。查看最近纠偏记录可区分“未发送原因”与实际发送量。

采样和动作参数怎样取舍

参数影响观察方式
平均笔数决定一批采样数量；数量增加需要等待更多有效测量。观察样本数及实际生产速度，不能按固定秒数理解。
发送后跳过笔数等待上次调整影响到达测量位置，期间不立即重复计算发送。对照材料走向、实际响应和跳过状态。
偏移下限、上限下限形成不动作死区，上限用于排除过大偏移。区分“在死区内”和“偏移超过上限”的未发送原因。
单次最大量限制单次实际输出幅度，保留方向。比较批次平均偏移与实际发送量。
最低速度、许可与完成点位控制何时允许采样、发送和开始下一次动作。同时查看速度、许可状态以及 PLC 是否清零完成点位。

正负方向必须结合安装和 PLC 约定确认。修改公式后先校验、保存并核对记录，不凭软件显示的正号推断机构物理移动方向。
