设置膜卷号

进入膜卷号配置，选择项目使用的获取方式，核对读取结果后再应用。手动输入时检查卷号是否正确；采用 PLC 或其他来源时，先确认连接和读取值。

“查看获取结果”只预览来源值，不执行换卷。部分项目支持 MES 共享文件等专用来源，按项目配置使用即可。

换卷处理过程

换卷后软件处理什么
  1. 固定上一卷的统计、料号和输出日期，清零相机帧数与同步计数，清理旧显示队列、测量累计和相关报警计数。
  2. 更新新卷显示、MES 卷号上下文和过程能力周期，清空新版纠偏采样，并通知相关模块换卷；启用光源自适应时触发新卷校验。
  3. 后台按换卷顺序保存卷号和尺寸累计、输出旧卷过程能力及 PLC 均值方差；随后按配置写入清米标志、编码器清零标志。启用正运动系统控制器时还会将 TABLE99 写为 0。
  4. 按已启用的保存和上传选项，继续刷新数据库缓存、保存旧卷地图与统计文件，并执行对应的后续输出。

清米、编码器地址未设置或系统控制器未启用时，不执行相应写入。各阶段单独记录结果，某阶段失败不等于整次换卷没有发生，也不会把失败动作全部自动重做。

新卷号已显示，不代表后台文件输出和 PLC 写入全部成功。发现计米未清零或旧卷报表缺失时，查看同一次“换卷#”的阶段记录，分别确认失败环节。软件写入返回成功也不等于设备已经完成机械动作。

手动、PLC 等来源统一经过换卷入口，实际卷号未变化时不重复清计数。规格牌与详细报警中的五项报警计数在换卷边界归零，已安排的 PLC 定时复位继续执行；参见检测报警计数。

换卷后的检查

核对主页新卷号、计米状态和上一卷输出文件。若新卷号已经显示，但报表或 PLC 点位不符合预期，查看同一次“换卷#”记录，定位具体失败阶段。参见日志与诊断。

测试读取与正式应用

  1. 从“料号管理 → 膜卷号配置”进入，选择手动、PLC 或当前项目配置的其他来源。
  2. PLC 来源核对读取点位、长度和字节顺序；其他来源核对对应的 URL、文件路径及配置。
  3. 填写有效位数的上下限并保存配置。有效位数只计过滤后卷号中的英文字母和数字，中文、符号和空格不计；0 表示不限制对应边界。
  4. 先点击“测试读取”检查最近读取中的原始值、处理结果和说明。确认正确后再“读取并应用”；手动方式使用“录入并应用”。
  5. 检查膜卷号记录中的读取、拒绝或换卷结果，再确认主页显示的新卷号。

测试读取不等于换卷；卷号校验失败时保留当前卷号。有效位数限制与 PLC 读取长度是两个不同参数。

手动结束与测试换卷

“手动结束 / 测试换卷”将当前卷号改为带“_已结束”的值，并执行正常换卷流程。运行中禁止该人工操作；用于结束当前卷时，应先核对当前状态和上一卷数据。

结束后，自动读取的旧卷号不会立即切回。同一卷号重复读取不会重复清计数。需要开始下一卷时，提供并应用真实的新卷号。

卷号没更新或换卷结果不完整

现象依次检查确认结果
读取到了值但主页卷号没变看读取记录中的原始值、过滤后值、有效位数及拒绝原因；确认是否只做了测试读取。正式应用成功且卷号确实不同，才进入新卷处理。
重复读取同一个卷号对照当前卷号，确认来源是否已切到新卷。重复值不重复换卷、不重复清计数。
新卷显示正常，设备米数未清零核对系统控制器启用、清米与编码器点位、连接和同次换卷阶段记录。分别确认清米写入、编码器清零及设备实际反馈。
旧卷报表暂未出现按旧卷号和换卷日期查找，检查对应保存开关及后台阶段日志。看到对应文件输出完成；新卷显示本身不代表文件已写完。

运行中可以查看状态，但人工修改卷号、来源配置及手动结束操作受运行状态和权限限制。出现“运行中禁止人工修改膜卷号或配置。”时先按正常流程停止检测。自动来源的正常换卷不等于人工编辑。
