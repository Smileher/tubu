瑕疵检测区域

进入瑕疵设置，选择相机并获取或加载图像。点击主图区域或表格行可以互相定位，选中区域黄色，其他区域绿色，未启用区域用虚线表示。重叠区域优先通过表格选择。

区域位置通过“编辑”窗口调整，主图不直接拖动或缩放检测区域。连涂和间涂均可对左、右、上、下四条边分别选择“固定位置”或绑定定位边缘，新增与编辑使用相同规则。固定方向填写原图像素坐标，绑定方向填写向区域内部的内缩像素；上下绑定需选择水平边缘。

固定位置在点击“应用”时自动限制到当前原图的有效坐标范围，并回显修正值。宽度为 8190 像素时，左右位置范围为 0～8189；上下位置按原图高度确定。负数修正为 0，超过最大坐标修正为最大值；非数字不接受。限幅后仍须满足左小于右、上小于下，否则应用失败。绑定边缘的抓取失败、方向错误或内缩后区域无效仍按定位异常处理，不自动改成固定位置。

点击“应用”只写入页面草稿，仍需点击页面统一“保存”。切换相机、图像、料号或离开相应页面会结束当前编辑会话。定位失败时可能沿用最近一次成功区域，但失败状态仍保留，不能把回退坐标当成本帧定位成功。

固定方向保持配置位置，不随其他边缘移动，也不应用该方向内缩；绑定方向按当前图像抓边结果更新。全部已绑定边缘有效、计算区域有效后才整体更新四边坐标。预览、试检、注册准备和在线检测使用同一定位规则；本帧定位失败即使沿用历史区域，也不能作为本帧注册成功的依据。

固定位置是检测图中的绝对位置，不表示距图像底部或右侧的距离。改变图像尺寸或使用不同高度的拼图后，应重新检查固定位置、检测范围和注册图。

区域设置顺序

  1. 选中当前相机，准备实际使用的标准图像。
  2. 先检查定位边缘，再选择需要的区域，调整位置、内缩和启用状态。
  3. 应用区域编辑，检查主图和表格对应关系。
  4. 完成模板注册与试检，确认后统一保存料号。

检测区域、注册模板与分类参数共同影响结果。更换图像、相机或料号后，重新核对当前编辑对象。

注册与分类

区域准备完成后，参见模板注册与 AI。需要按测量特征调整最终类别时，参见二次分类。

调整检出参数

在“瑕疵工具”中先选择相机并准备图像，再选择当前工艺对应的涂料、极耳、陶瓷等区域和检出页。碳膜检出可设置亮暗阈值差、噪点过滤、最小检出面积及滤波；部分模式还有面积补检、灰度自适应或边缘检测。

参数中的 px 表示像素，mm 和 mm² 表示标定后的长度及面积。不同页的阈值可能表示绝对灰度范围或相对背景差值，必须按当前参数名称理解，不能直接把一个模式的数值复制到另一个模式。

推荐的试检顺序

  1. 用标准图检查定位和注册是否正常。
  2. 用已知缺陷图执行对应分项测试，核对缺陷位置、类别、大小及灰度。
  3. 执行整图“检测”，检查定位、区域、检出、筛选与分类的组合结果。
  4. 用正常图检查是否出现误报，再检查边缘、接头等容易误判的样本。
  5. 核对结果后使用“保存全部参数”。子窗口的“应用”只更新当前草稿。

分项测试通过不代表整图流程完全相同；小图分类测试只检查分类器，参见模型测试。

工艺专用检测

界面按工艺提供虚边、涂胶、分时频闪、碳膜漏箔、削薄、间涂拼图或屏蔽间隙等选项。仅配置当前工艺实际使用的功能，先核对区域、图像尺寸和配套模型，再逐项试检。

间隔涂布的两种进图方式均在“瑕疵工具 → 间涂配置”中设置。完整操作、参数含义和无法拼图的判断见间隔涂布：拼图与间隙过滤；过滤命中会跳过当前整帧的尺寸与瑕疵检测。

检测区域无效、越界或定位失败时，优先处理区域与图像条件，不先通过放宽面积或灰度阈值掩盖问题。

项目主要影响核对方法
检测区域与内缩决定实际参与检测的范围；内缩过多可能漏掉边缘缺陷。同时查看区域边界和已知缺陷位置，先解决定位与越界。
亮暗阈值差改变与背景差异的检出条件，过宽松可能增加正常纹理误报。正常图和缺陷图成组比较，不仅检查一张缺陷图。
最小面积及噪点过滤抑制小区域，也可能去掉真实小缺陷。记录目标缺陷的测量面积，核对 px 与 mm²，逐步调整。
模板、AI 与分类分别影响参考背景、模型识别和最终类别。保留原图与整图检测结果，区分未检出、被过滤和被改名。

误报、漏检与结果不一致

  1. 确认当前相机、料号、原图与启用区域，检查缺陷是否确实位于有效区域内。
  2. 检查定位是否成功。即使画面沿用旧区域，也不能认为本帧定位正常。
  3. 用标准图核对注册，再用缺陷原图做整图检测，观察候选的位置和大小。
  4. 有候选但最终结果没有时，查长宽面积筛选、边缘／底涂过滤；有结果但名称不同则查模型标签和二次分类。
  5. 保存后再确认正式配置，记录修改前后参数和同一组图像的结果。

正常图通过与缺陷图检出都需要确认。只降低阈值让某张图检出，可能同时增加其他图像的误报。小图分类结果不代表整图业务结果，参见筛选与分类顺序。
