连接与保存

“工位数据交互中心”接收各工位原始尺寸、错位和瑕疵数据，按配置汇总、计算和分发。同一线体只在指定主控工位启动一套服务，其他工位连接它。

  1. 在“数据交互 → 工位数据交互”顶部“本机数据收发”区域勾选“启用本机数据交互”，按需选择“发送本机所有尺寸测量数据（含错位）”及“发送本机所有瑕疵数据”。发送开关控制本机自产数据上传，不控制接收；修改后保存生效。
  2. 指定主控机在右侧“本机汇总服务（仅主控机）”区域勾选“在本机运行数据交互服务器”并保存，启动汇总服务。本机连接方式切换为内存通道，不需填写远程服务器 IP 和端口，也不校验这些未使用的连接参数；原远程地址仍保留，关闭本机服务开关后重新显示。两个开关均启用并保存后，顶部“工具”菜单才显示“工位数据交互中心”，本页打开按钮才可用。
  3. 打开交互中心，在“数据主页”从下拉框选择本机监听 IP 并设置端口，保存设置；在“数据设置”维护各工位接收项。监听 IP 不允许自由输入。远程工位连接主控机可访问的网卡地址；仅监听 127.0.0.1 时，其他工控机无法连接。0.0.0.0 表示监听全部 IPv4 网卡，其他工位仍填写主控机的实际 IP。
  4. 其他工位保持本机服务器开关关闭，填写主控机 IP 和端口，启用本机数据交互，按需要选择发送本机尺寸测量数据（含错位）、发送本机瑕疵数据，保存后检查连接状态。主控机自身通过内存队列收发，不连接自己的 TCP 端口；接收项仍需配置。

本机服务开关与本机参与收发相互独立。关闭查看窗口不停止服务；关闭本机服务开关或退出主控机软件，会停止 数据中心 并断开其他工位。打开查看窗口本身不会启动服务。

网络与内存通道均使用原始数据；本机发送、数据中心 处理及本机接收消费使用独立快照。各 CCD 按自己的反转配置生成本机运行数据，不改写 数据中心 持有或向其他工位分发的原始值。

工位交互用于实时传输，断线期间不补发历史发送数据。远程断线时暂停消费已接收缓存，恢复连接后继续按原顺序处理；主程序接收缓存默认上限为 200 笔，达到上限时丢弃最早数据。连接恢复不表示故障期间的数据已经补齐。

同名工位的新 TCP 连接会接替旧连接。主控机本机工位与远程工位重名时，远程连接接管同名工位，本机内存通道暂不可用；冲突连接关闭后本机恢复接入。应为各工控机配置唯一工位名称，避免重复接管。

数据中心 监听、状态和分发

在“数据主页”选择服务 IP 和端口，查看本次运行的服务器发送、接收汇总；在底部状态栏核对服务和工位A～工位E的连接状态。主控机自身显示“本机已接入”和“本机内存通道”；远程工位直接显示 IP、上报版本和连接状态，悬停查看完整端点。远程版本不一致显示黄色，仍允许收发；建议核对并统一两端版本，不能仅凭黄色状态判断数据无法显示。未提供版本时显示“版本：—”。监听地址下拉框仅列出已连接网卡上已生效的 IPv4 地址，以及 127.0.0.1、0.0.0.0；尚在检测、重复或失效的地址不可选。已保存的 IP 当前不可用时保留显示并提示，需检查网卡连接并重新选择后才能保存，不会自动改成其他地址。保存前会再次检查地址，拒绝不可用地址时保持原监听与配置。

“工位接收配置”按目标工位决定接收哪些尺寸、错位和瑕疵数据。原始数据不会回传其生产工位；固定尺寸、错位数据集同一时刻只允许由一个在线工位提供。来源冲突的数据不进入正常转发和接收计数。

点击“保存设置”后生效。监听地址变更会断开现有远程连接，各工位按已保存的服务器配置重连；新监听启用失败时尝试恢复旧监听，并显示两次操作的实际结果。失败不会把新监听地址保存为当前配置。

监听或模板读取失败时查看窗口状态及主软件日志。损坏的 XML 不会被默认设置覆盖；对应模板不可用时停用该组错位计算。

处理与过滤

队列、发送超时和刷新使用内置默认参数，无需在界面逐项调整。数据中心 待处理队列及每个远程工位发送队列默认各保留 200 笔；满时淘汰最早数据并汇总记录。主程序接收业务队列仍独立保留 200 笔。

每个尺寸源默认保留 500 笔计算历史，超过后清空该源历史段重新积累；错位间隔绝对值必须小于历史容量。收发记录默认各保留最近 120 条，每条最多预览 8 项，其余数据仍参与正常业务。

界面每秒检查变化，只更新当前页面中变化的值；底部连接状态持续更新。窗口固定大小，不提供最大化、最小化或整页滚动，表格和详情区可局部滚动。重复点击入口会激活已打开的同一窗口。

在“数据设置”勾选“过滤异常尺寸与错位数据”并保存后，尺寸整组所有项的绝对值均不超过尺寸阈值时，整组不分发、不进入计算历史；只要有一项超过阈值，整组保留。数据中心计算的错位（含补偿）任一项绝对值超过错位阈值时，整组错位不分发，恰好等于阈值不因本规则过滤。尺寸、错位阈值默认分别为 0.05 mm、5 mm，界面说明显示当前配置的实际阈值。接收到的外部错位结果及瑕疵不受这两条过滤影响；取消勾选则跳过两条过滤。被过滤的尺寸仍有接收计数与接收记录，未分发不代表未收到。

错位计算与模板

在“数据设置”分别设置 A湿B湿、A干B干、A干B湿三组错位的计算开关、A/B 数据源、正负间隔及适用模板。正间隔 N 表示 A 第 n+N 笔配 B 第 n 笔；负间隔 -N 表示 A 第 n 笔配 B 第 n+N 笔。

在“错位计算模板配置”选择模板，维护顺序、错位名称、尺寸1、尺寸2、补偿和上下限。结果为“两数据源中尺寸1的合计－两数据源中尺寸2的合计＋补偿”；缺少指定尺寸时记录缺失名称，该项不计入合计。正数下限按负向下限参与判断。

尺寸名称以单个空格分隔，最后一个名称后保留一个空格。模板至少一行，错位名称不能为空或重复；数值保存到一位小数。先按料号核对名称与对应关系，再保存模板。

支持新建、重命名、删除模板及添加、删除行。重命名前保存未保存的配置与模板；被配置引用的模板不能删除，至少保留一个模板。保存模板后，引用它的计算使用新内容。直线工具导出的交互错位配置进入默认模板，并更新运行模板。

接收计数、实时记录和模拟

数据主页左右并列“服务器发送汇总”和“服务器接收汇总”，按工位、数据集显示本次服务运行的累计笔数及最后时间。发送汇总按目标工位统计：远程数据实际写入 TCP 后计数，本机数据投递内存队列后计数；仅进入发送队列不计数，也不代表对端显示或保存成功。接收汇总按来源工位统计：有效解析并通过来源检查后计数，后续被过滤不等于没有收到。模拟收发同样计入对应汇总。汇总不受实时明细保留条数限制，新服务启动时重新计数；数据集使用中文名称，完整编码可在实时记录和日志中核对。

“实时接收记录”“实时发送记录”显示时间、工位、数据集和有界摘要，可选择记录在下方查看名称、Code、数值或瑕疵面积。“已写入 TCP”表示发送完成，“已投递本机内存队列”表示完成本机投递，均不等于后续显示、保存或 MES 已完成。

“数据交互模拟”保留模拟接收、模拟发送和模拟错位计算。模拟数据进入正常计算与分发流程，可能进入各工位显示、保存和后续业务；停止生产并确认接收端状态后再操作。模拟接收不占用数据集唯一来源；模拟发送按在线工位已保存的尺寸与错位接收项执行；模拟计算使用当前已保存的数据源和模板，不等待历史间隔。

尺寸和错位顺序反转

按 A 湿、B 湿、A 干、B 干或对应错位组选择顺序反转。普通反转后，名称、Code、测量值、标准值及上下限仍跟随原测量对象。

例如尺寸1/50、尺寸2/30，反转后显示为尺寸2/30、尺寸1/50。总膜宽、点检尺寸和未启用尺寸不参与尺寸反转。该设置同时用于本机自产数据和交互接收数据。

同时反转名称和 Code

“反转后同时反转尺寸 Name 和 Code”会重新标识已反转的数据，不只是换显示顺序。上述示例会成为尺寸1/30、尺寸2/50。

启用前必须检查 MES、公式、虚拟图和动态补偿中按名称或 Code 建立的映射；不确定映射时保持此项关闭，先核对普通顺序反转是否已满足要求。

已接收但未显示、数据不一致时

主页可展开“接收与显示说明（按当前配置）”，查看当前料号启用的本机尺寸、错位数据集。主程序优先使用这些自产数据，不使用其他工位传来的同类数据用于本机显示、交互缓存及保存；该判定依据料号启用项，与工位 A/B 的名称、是否正在测量、发送开关无关。停止测量或关闭发送开关不会解除此规则。请按真实测量分工核对料号配置，不要仅为显示接收数据取消生产所需项目。

  1. 先看底部服务和目标工位是否接入，各机器的工位名称是否唯一；同名连接会接管原工位。
  2. 核对服务器已保存的目标工位接收项，数据不会回传生产工位。
  3. 检查“过滤异常尺寸与错位数据”：接收计数增加后仍可能被过滤，不进入后续分发。
  4. 若已有“已投递本机内存队列”记录，核对主页列出的本机自产数据集；投递不代表后续显示、保存或 MES 完成。
  5. 若仍异常，按同一时段的数据集与消息 ID 查主程序日志中的消费或解析失败原因；远程黄色版本警示本身不阻止收发。

比较同一卷、相同工位和数据集中的原始值、名称、Code 与显示顺序，再检查两侧反转设置。通信成功但数据含义不一致时，应先修正映射，不能只通过重复连接处理。

建立一次可靠的数据对应

  1. 选定同一卷和同一数据集，记录发送端某一尺寸的名称、Code 和测量值。
  2. 在接收端找到同一对象，先确认原始传输，再检查本机反转后的显示顺序。
  3. 普通反转只变顺序；同时反转名称和 Code 则会改变测量值对应的标识。按需要选择，不能混为一项。
  4. 如果这些值参与虚拟图、公式、MES 或动态补偿，逐项核对引用对象，最后保存并检查实际数据。

使用远程服务器时，出现服务器 IP 格式或端口范围提示，应先修正连接参数。本机内存模式无需填写远程地址，但交互中心的监听 IP、端口仍须有效。打开窗口不表示本机服务已启动，仍要确认连接与本次数据。

日志与异常检查

保留发送端与接收端同一时间的状态、数据集、名称及顺序，先核对映射和反转设置，再查通信错误。接收缓存有值不表示本笔数据严格按采集时刻对齐。

主程序的 Info 中搜索“多工位数据交互连接关闭”，核对工位、服务器、连接代次和关闭原因；Error 中搜索“多工位数据交互发送失败”“工位数据交互连接失败”或“多工位TCP接收或消息解析异常”，保留完整异常。Debug 中的“连接已断开”表示当前缓存等待消费，不是断线次数；“本段累计丢弃”按时段汇总缓存淘汰数量。

交互中心日志统一写入主软件日志，以“工位数据交互中心”搜索服务启停、配置和模板保存、监听故障、工位连接、同名接管、来源冲突、发送失败及队列淘汰。首次异常立即记录；持续的来源冲突、尺寸缺失、数据过滤及队列淘汰按分钟汇总，停止时记录剩余汇总数量。正常收发不逐笔写入运行日志；异常保留完整堆栈。先比较两端时间，再核对工位、端点和数据集，区分正常接管、对端关闭及实际通信故障。

资料收集方法见日志与诊断。
