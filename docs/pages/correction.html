新版纠偏设置

启用新版纠偏后，通过“功能 → 纠偏闭环设置”进入窗口。基础页配置偏移公式、偏移范围、单次最大量、平均笔数、发送后跳过笔数和最低速度；公式可使用已有测量尺寸和四则运算。

高级页配置数据过滤、纠偏设备和设备联锁。PLC 输出时需设置纠偏量点位：默认 FLOAT，单位 mm；选择 INT×100 时按该方式转换并向零截断。专用纠偏设备按所选类型配置通信参数。

点击“保存并应用”提交配置。切换实际发送设备要求停止检测且没有发送任务。未保存的设备选择不会改变后台发送目标。

自动纠偏的运行过程

  1. 开启自动纠偏后检查速度、测量结果、许可和设备状态。
  2. 按配置收集样本；低于最低速度或速度无效时清空采样并等待恢复，等于最低速度允许采样。
  3. 按偏移公式和过滤条件计算纠偏量；死区、超限或有效样本不足时不发送。
  4. 发送成功后按配置跳过若干笔；配置完成点位时写 TRUE，并等待 PLC 清零后再继续。

默认处于暂停状态。暂停后再开启、换卷或停止检测会清空采样。通信失败、发送结果不确定或纠偏 CSV 保存失败时会暂停后续发送，先核对提示和记录，避免重复动作。

完成点位表示软件数据发送完成，不表示纠偏机构已完成机械动作。许可点位留空则不限制，完成点位留空则不等待清零。使用联锁时要同时核对 PLC 逻辑。

手动微调与初始化

纠偏设置窗口提供手动微调，步长为 0.1～5 mm，精度 0.1 mm。自动纠偏开启时手动按钮禁用。一次发送结束后至少等待 1 秒；配置完成点位时，还须等待 PLC 清零。

“初始化”清空软件采样、跳过计数和暂停原因，下一次重新检查和初始化设备。它不会改变自动纠偏开关，不代替 PLC 清零，也不会重发旧纠偏量。

关闭设置窗口不会停止后台自动纠偏。有未保存修改时可选择保存、放弃或取消；放弃仅丢弃界面编辑，后台继续使用原已保存配置。

没有发送或设备没有动作

  • 先读窗口顶部运行提示，区分未开启、低速、死区、超限、样本不足、许可不满足和通信失败。
  • 确认选中的设备已连接，PLC 量输出点位、单位和联锁点位与现场一致。
  • 完成点位一直未清零时，先检查 PLC 是否已接收并执行复位逻辑，不连续点击手动发送。
  • 软件显示发送成功而机构不动时，继续检查 PLC 数值、许可、设备模式和机械状态，不能直接判定软件重复发送即可恢复。

配置采样与偏移范围

先通过“添加尺寸”选择实际参与计算的数据，再填写和校验偏移公式。平均笔数决定一个独立采样批次，发送后跳过笔数用于等待材料或设备响应，最低纠偏速度用于排除低速过程。

偏移绝对值不超过下限时不发，超过上限时也不发；单次最大纠偏量则限制一次实际发送幅度并保留方向。它们分别用于死区、异常保护和单次动作约束，不应当作同一个参数。

启用异常数据过滤时，按与批次中位数的偏差剔除样本；测量失败始终排除。过滤后达不到至少有效笔数时不发送。查看最近纠偏记录可区分“未发送原因”与实际发送量。

采样和动作参数怎样取舍

参数影响观察方式
平均笔数决定一批采样数量；数量增加需要等待更多有效测量。观察样本数及实际生产速度，不能按固定秒数理解。
发送后跳过笔数等待上次调整影响到达测量位置，期间不立即重复计算发送。对照材料走向、实际响应和跳过状态。
偏移下限、上限下限形成不动作死区，上限用于排除过大偏移。区分“在死区内”和“偏移超过上限”的未发送原因。
单次最大量限制单次实际输出幅度，保留方向。比较批次平均偏移与实际发送量。
最低速度、许可与完成点位控制何时允许采样、发送和开始下一次动作。同时查看速度、许可状态以及 PLC 是否清零完成点位。

正负方向必须结合安装和 PLC 约定确认。修改公式后先校验、保存并核对记录，不凭软件显示的正号推断机构物理移动方向。
