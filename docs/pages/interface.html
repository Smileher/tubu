认识主界面

顶部显示工位号、当前料号和膜卷号。工作区按布局展示相机图像、尺寸与错位表格、瑕疵列表、统计、曲线、虚拟图及生产信息。侧边功能入口用于进入料号管理、直线工具、瑕疵工具、参数补偿、数据交互、报警设置、MES 配置和系统设置。

名称、入口和展示模块可能随配置及已保存布局不同。先依据功能名称查找，不以固定屏幕坐标判断功能位置。

点击侧边功能入口后，目标按钮先显示待切换状态，工作区顶部显示细进度条；页面准备完成后再切换选中标记。准备期间重复点击不会重复打开页面。若取消未保存参数确认、登录或权限检查未通过，仍停留在原页面。首次打开复杂页面可能需要稍等，进度条消失后可正常操作。

快速操作栏左侧固定显示运行／停止按钮：绿色“运行”用于开始检测，红色“停止”用于停止检测，悬浮时状态色保持一致。锁定图标表示当前不可操作，应先查看提示，颜色本身不代表已经具备启动条件。

纠偏快捷按钮显示“启用纠偏”或“停止纠偏”，用于切换自动纠偏开关，并与纠偏设置窗口同步。开启开关不表示已发送纠偏量，仍需满足权限、功能启用、设备及联锁条件；详见自动纠偏的运行过程。

停止状态离开系统主页后，全部快速操作按钮锁定，速度、米数、脉冲和时钟继续显示。切换页面时不额外显示快速操作提示行，顶部栏高度保持一致。返回主页后，各按钮仍按设备、初始化和当前任务状态决定是否可用。若自动运行在非主页启动，红色“停止”按钮仍可用，其他快速操作保持锁定；启停处理中仍需等待。

运行时侧边栏自动隐藏，工作区扩展到原侧栏位置；停止或启动失败后恢复显示，原侧栏宽度设置保留。停止按钮固定在快速操作栏左侧，不随其他快捷按钮横向滚动。

调整显示布局

  1. 停止检测，通过“界面 → 布局编辑”进入编辑。
  2. 按需要调整页签、选择展示模块，并拖动模块到合适的停靠区域；同一页可以组合相机图像与结果表格。
  3. 检查各模块内容是否完整、文字是否被遮挡，保存布局并退出编辑。
  4. 返回系统主页检查正常显示后，再开始检测。

模块可以使用自定义显示名称，名称变化不代表测量对象或数据源发生改变。布局只调整显示组织，不代替尺寸、瑕疵或保存参数设置。

启动时首页模块未完整初始化，会跳过历史布局加载并禁止保存，保留布局原文件和备份，避免将暂时不可用的相机图像或统计模块误删。此时先处理启动加载提示和 Error 日志，恢复正常后再检查布局，不反复覆盖保存。

阅读实时结果

尺寸表、错位表与曲线应按数据集和项目名称对应查看。瑕疵列表记录类别、大小、灰度和位置；局部图用于观察细节，大图用于确认缺陷在原图中的位置。统计表展示所选统计范围的汇总，不能用一条实时结果推算全部累计数据。

需要调整统计列、区域融合或显示顺序时，参见结果统计；需要编辑示意图时，参见虚拟图。

检测结果指示

“检测结果”显示本机有效生产检测的状态：正常显示绿色 OK；任意相机组的尺寸、错位或瑕疵出现 NG，立即显示红色 NG，不等待其他组。WARN 不按 NG 显示，未启用尺寸及点检尺寸不参与产品 NG 判定。交互接收的表格数据和历史记录不参与此指示。

红色 NG 从最后一次 NG 起保持 3 秒，期间再次检出 NG 会重新计时；收到 OK 会记录最新结果，但不会提前覆盖红色。保持结束后按最新有效结果更新，超过 3 秒没有有效新结果时显示灰色空白，不自动变成 OK。未开始检测、停止或切换料号时也显示灰色空白。空结果包不会延长显示时间；实际执行瑕疵检测且未检出瑕疵属于正常结果。

检测结果显示不受“尺寸声光报警”“瑕疵声光报警”开关控制。关闭声光报警后仍会正常显示 NG；这些开关只控制对应三色灯和蜂鸣器，详见检测声光报警。

语言、主题和显示大小

“界面 → 修改语言”支持简体中文、繁体中文、英文、韩文、日文、泰文、德文和越南语；“切换深浅主题”调整软件外观。在“系统设置 → 显示设置”调整主页文字大小后，尺寸、错位、缺陷实时表格、尺寸点检、过程能力统计的表头、时间及数值同步变化，已有数据无需清空。主页日志使用固定的默认字号；侧边菜单宽度在停止检测时可见。

帮助中心的明暗主题和字号独立保存，不会改变检测软件参数。软件中设置自定义 Logo，也不会改变本手册固定的默认标识。

查阅与导出手册

通过“帮助 → 操作手册”打开手册。首页可按任务路线查阅，或直接搜索操作、参数与提示文字。搜索支持常用别名、多个关键词和分类筛选，点击结果可定位到章节并突出命中词；没有完全匹配时会单独展示相关建议。桌面左侧展开分类，右侧显示本篇目录；手机点击顶部“目录”打开导航。浏览器前进、后退可返回之前的页面。

每次打开右上角“导出”时默认选择整本手册，也可切换为当前文章。Word 下载可编辑 DOCX，包含封面、分类目录、文章分页和页脚页码。目录按网页上的分类、文章、章节三级排列，当前文章导出只包含所属分类及该文章的章节。目录标题和内部链接在导出时已生成，未启用编辑也能看到完整目录；打开文件时不强制更新域。需要目录页码或修改正文后，可在 Word 中右键目录，选择“更新域”及“更新整个目录”，由 Word 根据实际排版生成页码；受保护视图下需先启用编辑。目录链接通常使用 Ctrl+单击跳转，具体以阅读软件为准。

文件名为手册或文章名称加“-v年月日时分秒”，时间取导出时的本机时间。导出过程可离线使用，内容不包含导航控件和搜索高亮。帮助网页本身不提供 PDF 导出；需要 PDF 时可在 Word 中使用“另存为 PDF”。需要带页码的 PDF 目录时，应先在 Word 中更新目录再另存。

章节标题旁的“#”可复制直达链接；字号、主题和最近阅读位置在浏览器允许时保存在本机，存储不可用也能正常阅读。

页脚“AI 知识文档”提供包含全部分类、章节、步骤及表格的 Markdown 文件，可用于知识检索。点击后由浏览器打开或下载；文件开头提供在线手册及离线首页链接。
