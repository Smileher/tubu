新增分析项目

通过“功能 → 过程能力分析”进入设置。主界面需在布局中放置对应分析模块，才能持续查看结果。

  1. 新增项目，选择当前料号中的宽度或错位数据源与统计指标。数据源名称下拉同时提供宽度和错位，无需另选类型。
  2. 统计项目设置统计点数、最少样本数和需要的子组参数；按分钟统计时，在页面顶部勾选“按时间分段统计”并填写全局统计周期。原始数据不使用这些统计参数。
  3. 按需要勾选“启用”“显示表格”“显示趋势图”和“按尺寸规格过滤”。表格与趋势可独立显示，不需要再启用图表总开关。
  4. 非原始数据项目按需填写报警限与 PLC 地址；CPK 核对自动规格及能力阈值，再保存配置。

同一宽度要同时观察平均数和标准差时，应新增两行并选择不同指标，不用一组限值混合解释两个指标。

结果限值和 CPK 规格

平均数、标准差、方差、极差和 COV 的结果上下限限制的是统计结果。等于边界不算超范围，留空表示不限制对应一侧，填 0 是真实边界。

CPK 规格从当前料号的尺寸工具自动读取，不手填。规格 = 标准值 + 上下偏差，不再叠加补偿。例如标准值 100 mm、下偏差 -0.5 mm、上偏差 0.5 mm，对应规格 99.5～100.5 mm。规格错误应回尺寸工具核对并保存。CPK 行的报警下限用于能力预警，例如 1.33；报警上限不适用。严重／停机阈值和连续次数独立保留，在详情中核对。

样本不足或没有 CPK

检测失败、非法值、标定失败和过渡数据不计入有效样本，真实尺寸 NG 数据默认保留；勾选规格过滤后，超规格数据排除。点数模式的样本窗口不能小于最少样本数；输入不符合要求时，保存会提示具体项目。

CPK 使用组内波动，需要合理子组和至少两个完整子组。样本不足或波动为零时可能没有可显示值，空值不能当作 0 或正常。过程不稳定时，不能仅凭 CPK 较高判断质量正常。

报警、停机与复位

统计越限还要结合连续异常次数、报警开关和严重阈值判断，不是一次越限就必然停机。弹窗报警与停机联动独立，关闭弹窗不等于禁止停机。

原始数据行仅用于查看，统计点数、最少样本、统计报警和停机单元格禁用；即使从其他指标切换时保留了旧报警参数，也不会触发本行统计报警。原有单点尺寸报警继续独立执行。

启用停机联动前核对 PLC 地址。停机锁存后需人工确认并成功完成 PLC 复位才解除；同卷复线会重新采集实时窗口，本卷累计数据保留。单次尺寸超规格仍由尺寸报警独立处理。

保存和重新统计会清样本

保存配置都会清空实时与累计运行样本、最新原值和趋势，开始新统计周期。“重新统计”也会开启新周期，不用于普通查看。时间模式从新周期启动时刻重新计时，尚未满周期的数据不生成统计结果。

配置全局共用，切换料号后应确认报警限和 PLC 地址是否适用。统计样本不跨料号或跨卷混用。

原始数据与六种统计指标

指标含义使用时注意
原始数据表格显示最新有效测量值，折线逐笔记录有效原值，保留原始精度。不等待统计周期或最少样本，仅展示；有效性与可选规格过滤仍生效。
平均数当前窗口有效尺寸的平均值。单位与尺寸相同；平均合格不代表每一笔都合格。
标准差反映尺寸的离散程度。单位与尺寸相同；比较时保持样本与统计范围一致。
方差按有效样本计算波动，采用样本方差。毫米尺寸对应 mm²，不能套用标准差限值。
极差当前窗口最大值减最小值。会受到个别极端测量影响，结合原图检查。
CPK结合均值、组内波动和产品规格评估过程能力。规格取自尺寸工具，子组不足或波动为零可能没有结果。
COV标准差除以平均数绝对值，表示相对波动。无量纲；0.01 相当于 1%，平均数为零时没有有效值。

统计点数不是等待秒数

未勾选“按时间分段统计”时，窗口使用最近 N 个有效点。默认统计点数 200、最少样本 30；最少样本不得低于 5，统计点数不能小于最少样本。启用稳定性检查时，还需要满足“稳定性基线 + 1”，实际开始判定使用它与最少样本中的较大值。

例如最少样本 5、稳定性基线 20 且启用了稳定性检查时，不能期待第 5 个点就完成稳定性判定。稳定性基线允许的下限为 10，统计点数必须大于基线。

按尺寸工具规格过滤样本

为需要的项目勾选“按尺寸规格过滤”并保存。页面不单列过滤范围，实际范围直接读取当前料号尺寸工具：下限为标准值加下偏差，上限为标准值加上偏差，不额外叠加补偿，不固定写成 ±0.5 mm。等于边界的数据保留，超出范围的数据不参与该项目统计或原值展示。

过滤默认为关闭，点数和时间两种模式均可使用。数据源未匹配或规格无效时，需要修正尺寸工具或重新选择数据源后再启用过滤。该设置不改变单点尺寸判定、原始检测结果或其他统计项目。CPK 项目启用过滤后，结果只代表过滤后的样本。

按完整时间段统计

  1. 在过程能力分析配置页面顶部勾选“按时间分段统计”。
  2. 填写全局统计周期，单位 min，允许 1～1440 的整数；例如 10 表示每 10 分钟结算一段，不是每 10 分钟只抽取一个测量值。
  3. 保存后从统计周期启动时刻计时，六种统计指标共用起点。段内收集全部有效数据，不受“统计点数”截断；原始数据始终按有效测量逐笔更新。

样本按统计服务接收时刻归段，横轴使用完整段结束时间。例如周期在 10:03 启动、周期为 10 min，则先统计 10:03～10:13，再统计 10:13～10:23。段结束后的新数据进入下一段。配置保存、换卷、切换料号或重新统计都会重新计时，不补算未满的尾段。

表格在完整段结束后更新，统计报警也只对每段结果判定一次。例如连续 3 次异常表示连续 3 个分段判定，不能按原来的逐笔频率理解。没有有效样本、样本不足、CPK 子组不足或 COV 无法计算时，不产生有效数值，不把空值当作 0。停机锁存及人工复位仍按原规则执行。

配置与查看集中趋势图

  1. 在同一个配置页面添加项目，选择原始数据或统计指标并启用。同一数据源需要不同指标时，分别新增行。
  2. 勾选项目的“显示趋势图”并保存；“显示表格”可独立勾选。
  3. 在主界面布局中放置“过程能力趋势图”。单图占满可用区域，多图根据容器宽高自动分配行列，每行铺满，不保留空的末尾格子。

原始数据和六种统计指标均支持折线图，不限制错位或宽度路数。每张图与对应表格项目共用数据源及过滤条件：时间统计绘制完整段结果，点数统计绘制最近 N 点的窗口结果，原始数据绘制逐笔有效值。标准差即 1σ，沿用样本标准差；方差单位为 mm²，均值、标准差、极差和原值为 mm，CPK、COV 无量纲。

各图仅在内存保留最近 50 点：时间统计对应 50 个完整段，原始数据对应 50 笔有效原值。原值逐笔缓存，表格和曲线合并刷新，不为每帧重建全部图表。软件重启、配置保存、换卷或重新统计后重新采集。样本不足或无法计算处留空；关闭图表或切换布局不停止统计和报警。

没有结果或一直提示采集中

  1. 确认项目已启用；查看表格需勾选“显示表格”并放置分析模块，查看曲线需勾选“显示趋势图”并放置趋势图模块。
  2. 查看数据源是否匹配当前料号、对应尺寸是否启用；出现“数据源未匹配，请检查当前料号”时重新核对选择。
  3. 统计项目检查有效样本数与开始判定要求；原始数据检查是否收到新的有效测量以及是否被规格过滤。
  4. CPK 再检查自动读取的规格、子组和波动；空结果不能当作 0 或正常。
  5. 报警与停机分别检查阈值、连续次数、开关及 PLC 返回；原始数据行不参与统计报警。
