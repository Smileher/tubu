参数补偿

  1. 进入参数补偿，先核对当前数据集和尺寸列顺序。
  2. 使用 CSV 数据时，按尺寸顺序输入软件显示值，数字用空格分隔，再点击“数据解析”。
  3. 填写人工测量值，点击“计算”，核对差异是否在允许范围内。当前数据集如有负的人工测量值，会列出对应尺寸和数值并停止计算；修正后重新计算。普通尺寸、错位和比例校准都要检查。
  4. 点击“确认”，再点击右侧“保存”。确认不等于已经正式保存。

本页“保存”只提交当前数据集，其他数据集未保存修改仍保留；离开页面选择保存时，会一次提交本页所有有修改的数据集。权限和差异范围检查继续生效。

按钮按“数据解析 → 计算 → 确认 → 保存”顺序操作。CSV 输入框下方显示导出目录：D:\Data\FilePDF。

“导出表单”为手动导出，可能包含尚未保存的值；当前数据集保存成功后也会自动导出。两种方式都会同时生成 PDF 和 Excel（.xlsx），文件同名、在同一目录，成功提示会列出完整路径。手动表单标题标有“手动导出”。

两种格式的九列顺序和数值一致：类型、现补偿值、下限、标准值、上限、软件测量值、软件显示值、人工测量值、差异值。Excel 数值显示三位小数。

若一种格式导出失败，仍会尝试另一种，提示会分别说明结果。导出失败不会撤回已经保存的补偿参数，请按提示核对文件占用、目录及权限后重试。

确认与保存范围

计算后先核对数据集和人工测量值，再确认补偿。当前页保存与离开页面时保存的范围不同；未保存的输入仍属于页面草稿。参见保存与放弃修改。

理解各列数值

  • 软件测量值是原始测量值。
  • 软件显示值 = 软件测量值 + 默认补偿值 + 现补偿值。
  • 总补偿值 = 默认补偿值 + 现补偿值。
  • 差异值 = 人工测量值 - 软件显示值。

默认补偿值由动态补偿维护，人工或 CSV 补偿更新现补偿值。数据反转前后都要核对尺寸顺序，不能把人工测量结果填到另一条尺寸列。

差异限制与补偿记录

点击“补偿差异设置”打开设置窗口。同一时间只打开一个窗口；重复点击会激活已打开的窗口，保留尚未确认的输入。关闭后可再次打开。

计算时先按尺寸名称检查允许差值范围：名称含“极耳”“陶瓷”“碳膜”时用对应范围，其余名称用“其他”范围（默认 -5 到 5）。范围包含两端，超出时先核对人工值和当前数据集。

通过范围检查后，差异落在“差异忽略范围”内（包含两端）时，原补偿不变；超出时补上完整差异。例如忽略范围为 -0.15 到 0.15，差异 +0.12 不补，+0.20 则补 +0.20。默认两端为 0，沿用原方式。此规则只影响“计算 → 确认”生成的补偿，不影响手动改现补偿或比例校准。

比例校准另按允许差值检查，不分正负，默认 0.500；相差不超过此值才可继续，设为 0 时只允许数值相同。原有免检查人员规则保留。

“补偿日志”可查看操作批次和各项变更。“补偿值一键清零”会改变补偿参数，执行前核对当前数据集和提示范围，之后检查实际保存结果。

动态补偿

  1. 从“功能 → 动态补偿”进入，选择需要启用的规则。
  2. 按物理意义建立“目标尺寸 → 基准尺寸”映射，不仅按名称相同或表格同列匹配。
  3. 配置累计周期、跳过距离和补偿限制，检查运行状态后保存配置。
  4. 观察两侧有效样本和补偿变化；需要重新收集时使用“清空累计数据”。

目标侧直接累计，基准侧先跳过距离笔数；两侧有效数据达到周期笔数的 80% 后计算均值或中值。标准值为 0，或单笔相对标准值偏差达到 80% 的数据被排除。

补偿差值为基准值减目标值；绝对值不超过 0.02 时不调整，每轮最多调整 0.10，累计默认补偿仍受正负限值限制。使用工位数据反转时，先核对映射含义再启用。

补偿计算示例与核对

例如软件测量值为 100.00 mm，默认补偿为 0.05 mm，现补偿为 0.02 mm，则软件显示值为 100.07 mm。人工测量值为 100.10 mm 时，差异为 0.03 mm。这个例子用于核对列含义，实际是否允许调整还受差异、次数和时间限制。

  1. 先确认人工测量与软件对应同一产品位置、同一尺寸和同一数据集。
  2. 输入或解析数据后逐列检查，尤其注意 A/B 面与反转后的顺序。
  3. 计算、确认后检查候选补偿，再保存当前数据集。
  4. 观察保存提示、实际显示与补偿日志。表单导出失败应与参数保存结果分开处理。

动态补偿完成但数值没变

先看目标和基准两侧是否都有足够有效样本，再看距离跳过、差值死区、单轮调整限制及累计限幅。日志中的“计算完成，默认补偿未变化”不一定是错误，可能是差异位于死区内或已达到限制。

动态补偿更新默认补偿，人工补偿更新现补偿，两者共同影响显示值。动态补偿接受的更新先在运行内存生效，再等待三分钟合并保存；保存异常时应核对后台重试记录，不以页面输入是否改变推断文件是否已写入。
