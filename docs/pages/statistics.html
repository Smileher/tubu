统计和单次结果的区别

主界面尺寸统计、瑕疵统计、直方图和分布图汇总多个检测结果，实时尺寸表与瑕疵列表则展示具体测量。比较数据时先核对膜卷、面别、相机和统计范围。

统计显示、报警计数和过程能力样本是不同用途。人工报警复位不会清空产量或普通瑕疵统计；切换统计显示范围也不等于重新检测。

尺寸统计设置

  1. 进入“系统设置 → 尺寸统计设置”。
  2. 选择默认统计范围、表格方向和百分比小数位。
  3. 勾选 NG 个数、检测次数、NG 率、优率等需要显示的项目。
  4. 选择当前料号中需要显示的尺寸，使用上移、下移调整顺序，检查预览。
  5. 点击“保存并应用”。尺寸显示与顺序随料号保存。

每个尺寸独立计算：NG 率 = NG 个数 ÷ 检测次数，优率 = 100% - NG 率。没有有效检测时，不能把空值当作实际优率。

瑕疵统计设置

进入“系统设置 → 瑕疵统计设置”，选择统计范围、表格方向和小数位，再设置结果区域、NG 次数、检测次数、NG 率、优率、瑕疵占比及总计等显示项。

勾选需要的面别、相机和瑕疵名称并调整顺序，按需要启用直方图和分布图。预览中的数值是演示数据，不能用于判断本卷真实质量。

区域融合和图表

需要合并多个检测区域时，新增融合组、填写组名称并选择实际区域。保存前检查组成员和列展示模式，避免把相同名称但不同相机的区域混为一项。

直方图用于查看各类分布，瑕疵分布图用于按位置追溯；检查细节时回到对应瑕疵记录与图像。图表是否显示还取决于主页布局中是否放置相应模块。

保存与导出

“保存并应用”提交当前统计配置；“放弃修改”恢复已保存配置，“恢复默认”用于重置页面设置，执行前核对提示。

瑕疵统计中的“导出 CSV”导出统计页最后显示的实际数据，不采用尚未保存的预览修改。需要统计 PDF 报表时，使用该页已有报表开关并检查实际输出。

次数、个数与统计范围

瑕疵统计提供按卷和按天查看。跨天生产同一卷时，整卷累计与当天切片的时间范围不同，数值不必相等；比较导出结果前先核对范围。

一张图可能检出多个瑕疵，“NG 次数／NG 图像数”与“瑕疵个数”不是同一含义。同一相机不同区域也可能在同一张图上同时命中，合并查看时不要简单相加推算唯一 NG 图像数。

统计与画面不一致怎样检查

  1. 核对统计按卷还是按天，以及料号、卷号、面别和相机。
  2. 核对尺寸、瑕疵名称和区域融合成员，确认比较的是次数还是个数。
  3. 检查当前页面是否只是未保存的演示预览；正式导出使用最后显示的实际统计。
  4. 核对主页布局是否放置了相应统计模块，模块缺失不等于没有检测结果。
  5. 需要追溯单个缺陷时，转到对应记录和原图，不只从比例或柱状图推断。
