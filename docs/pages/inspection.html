瑕疵检测区域

HALCON 模式的区域保存值、图像像素提示和检出结果行列均为原始图像坐标，显示缩放不改变这些数值。旧料号首次读取时自动将历史半尺寸区域转换一次并保存版本标识，原文件保留备份；再次启动不会重复放大。长度、宽度和真实区域面积使用毫米及平方毫米，与像素坐标分开。

旧 HALCON 区域的负数、超出图像边界或退化边界也会完成坐标转换，不因某个区域影响整个料号迁移。迁移保留原有坐标含义，不自动截断或删除区域；部分越界区域定位后按当前图像内的有效范围检测。完全没有图内有效范围的区域仍需检查，不能作为有效检测区域使用。

进入瑕疵设置，选择相机并获取或加载图像。点击主图区域或表格行可以互相定位，选中区域黄色，其他区域绿色，未启用区域用虚线表示。重叠区域优先通过表格选择。

区域位置通过“编辑”窗口调整，主图不直接拖动或缩放检测区域。连涂和间涂均可对左、右、上、下四条边分别选择“固定位置”或绑定定位边缘，新增与编辑使用相同规则。固定方向填写原图像素坐标，绑定方向填写向区域内部的内缩像素；上下绑定需选择水平边缘。

每条边的调整值旁提供减、加按钮，短按减少或增加 1 像素，长按约 0.4 秒后连续调整；松开、移出按钮或切换窗口后停止。固定模式调整位置，绑定模式调整内缩；位置不超出原图边界，内缩为 -9999～9999 的整数，正数向内缩、负数向外扩，单位均为原图像素。按钮只修改窗口输入，仍需点击“应用”检查四边关系及图像边界，再保存料号。

固定位置在点击“应用”时自动限制到当前原图的有效坐标范围，并回显修正值。宽度为 8190 像素时，左右位置范围为 0～8189；上下位置按原图高度确定。负数修正为 0，超过最大坐标修正为最大值；非数字不接受。限幅后仍须满足左小于右、上小于下，否则应用失败。绑定边缘的抓取失败、方向错误或内缩后区域无效仍按定位异常处理，不自动改成固定位置。

点击“应用”只写入页面草稿，仍需点击页面统一“保存”。切换相机、图像、料号或离开相应页面会结束当前编辑会话。定位失败时可能沿用最近一次成功区域，但失败状态仍保留，不能把回退坐标当成本帧定位成功。

固定方向保持配置位置，不随其他边缘移动，也不应用该方向内缩；绑定方向按当前图像抓边结果更新。全部已绑定边缘有效、计算区域有效后才整体更新四边坐标。预览、试检、注册准备和在线检测使用同一定位规则；本帧定位失败即使沿用历史区域，也不能作为本帧注册成功的依据。

固定位置是检测图中的绝对位置，不表示距图像底部或右侧的距离。改变图像尺寸或使用不同高度的拼图后，应重新检查固定位置、检测范围和注册图。

区域设置顺序

  1. 选中当前相机，准备实际使用的标准图像。
  2. 先检查定位边缘，再选择需要的区域，调整位置、内缩和启用状态。
  3. 应用区域编辑，检查主图和表格对应关系。
  4. 完成模板注册与试检，确认后统一保存料号。

检测区域、注册模板与分类参数共同影响结果。更换图像、相机或料号后，重新核对当前编辑对象。

注册与分类

区域准备完成后，参见模板注册与 AI。需要按测量特征调整最终类别时，参见二次分类。

调整检出参数

检测参数按“涂膜检测”“非涂膜检测”“其他检测配置”分组。先选择上级页签，再选择对应的检测页；各入口沿用当前模式的显示条件，组内没有可见页面时隐藏该组。

碳膜瑕疵检出的常用参数分为通用处理、图像滤波、候选筛选、亮暗提取四组，按组调整对应参数。左右区域保持等宽，图像区保留较大的查看面积。

页面右侧依次为检测参数、筛选区、检出结果和操作按钮。参数按可用宽度横向排列并自动换行，高度随内容展开。启用项位于左上，注册或模型文件时间位于右上，当前项目操作位于右下。悬停参数可查看简易说明。筛选区按当前模式显示 AI 结果筛选表，或特征分类列表及其特征条件表；切换到不使用该筛选区的检测页时，检出结果自动使用释放的空间。

底部“整图检测”和原有“保存”等操作固定显示。窗口很小或系统缩放较大、内容无法同时容纳时，仅右侧整体纵向滚动，参数区不再单独滚动。AI 过滤兜底参数及说明随宽度换行；特征分类列表与特征条件表并排显示，说明及新增、删除、上移、下移按钮位于两张表的底部，简短说明与操作按钮尽量同行，详细含义可悬停查看。

上级页签检测页面
涂膜检测碳膜瑕疵检出、特定瑕疵预检测、碳膜过滤检测。使用对应算法模式时，显示碳膜瑕疵检出2或涂料区检测-新。
非涂膜检测区域亮暗瑕疵检测、极耳检测、虚边检测。区域亮暗瑕疵检测内直接设置亮瑕疵（边缘漏金属）、暗瑕疵（边缘破损）参数，并提供区域设置与试检。使用对应算法模式时，显示极耳区检测-新、陶瓷区检测-新。
其他检测配置过滤底涂、目标检测、间涂配置。其中间涂配置仅在间涂料号中显示。

在“瑕疵工具”中先选择相机并准备图像，再选择当前工艺对应的涂料、极耳、陶瓷等区域和检出页。碳膜检出可设置亮暗阈值差、噪点过滤、最小检出面积及滤波；部分模式还有面积补检、灰度自适应或边缘检测。

参数中的 px 表示像素，mm 和 mm² 表示标定后的长度及面积。不同页的阈值可能表示绝对灰度范围或相对背景差值，必须按当前参数名称理解，不能直接把一个模式的数值复制到另一个模式。

碳膜瑕疵检出中，滤波宽、高和运算系数按半尺寸工作图的像素设置；噪点过滤按原图像素面积（px²）理解，小于设定值时剔除，等于时保留。例如200约为10×20像素的实心面积，对应半尺寸工作图50个像素的面积，实际形状还受缩放和形态处理影响。“最大检出个数”在每个区域分类前按候选面积筛选，最多保留设定个数；面积并列时按原候选顺序取舍，已剔除的候选不能由AI补检找回。

亮、暗阈值差值用于模板校正图的候选提取；过滤兜底中的亮、暗灰度差用于后续补检，单位均为灰度级，不是百分比。例如亮阈值15、亮灰度差50，不表示统一按50检出：AI非OK候选的长、宽或面积筛选未达标后，才统计比所属ROI背景亮至少50灰度级的像素，并判断有效面积；亮、暗面积分别判断，不相加。特征分类的“未知缺陷最小检出”不控制AI补检产生的未知。

特征分类的等效椭圆主半径、次半径和最大内圆半径以mm设置，使用横纵平均分辨率换算。使用过旧版半径规则的料号，应以已知缺陷样本重新核对阈值；未启用半径特征的规则不受此项影响。

推荐的试检顺序

特征分类使用页面底部的“整图检测”验证。根据主图标注的最终类别核对规则；未命中任何规则的候选按“未知缺陷最小检出”决定是否保留，二次分类还可能改名。名称为 OK（不区分大小写）的结果会像在线检测一样被剔除。绿色“被过滤”标注的覆盖范围见过滤结果显示范围。

  1. 用标准图检查定位和注册是否正常。
  2. 用已知缺陷图执行对应分项测试，核对缺陷位置、类别、大小及灰度。
  3. 执行“整图检测”，检查定位、区域、检出、筛选与分类的组合结果。
  4. 用正常图检查是否出现误报，再检查边缘、接头等容易误判的样本。
  5. 核对结果后使用“保存全部参数”。子窗口的“应用”只更新当前草稿。

分项测试通过不代表整图流程完全相同；小图分类测试只检查分类器，参见模型测试。

碳膜上方“本项试检”只显示候选提取结果，也执行配置的均值滤波和灰度补偿；“整图检测”还包含特征分类或AI分类、筛选和二次分类。普通碳膜检测需要注册标准模板。灰度补偿失败、候选裁剪或边缘屏蔽异常、AI推理失败、返回空标签或标签未配置时按检测异常处理；试检查看错误提示，在线查看Error日志，不能据此认定本帧无缺陷。

进入“非涂膜检测 → 区域亮暗瑕疵检测”，设置亮瑕疵、暗瑕疵的灰度范围、面积范围和最小长度，点击“边缘过滤区”设置区域，点击“检测”执行试检；页面高度不足时可使用参数区右侧的垂直滚动条查看底部操作项。原“碳膜漏箔检测”已合并到此入口，漏箔须位于启用的边缘区域内，并满足亮瑕疵的灰度、面积和最小长度条件；短于最小长度的缺陷会被过滤。

“最大检出个数”表示每个检测区域中，亮、暗缺陷各自的最大检出数量，悬停输入框可查看相应说明。取值范围为1～100的整数，旧料号默认2。两类缺陷分别计数，按连通域实际面积从大到小保留前N个；面积相同时按原连通域顺序选取，严格不超过上限。例如两个区域、上限为2时，在线最多返回4个边缘漏金属结果。选取依据为连通域实际面积，结果表中的尺寸与面积仍按原边缘检测口径显示。

页面“本项试检”使用当前相机的参数和区域草稿，试检边缘漏金属与边缘破损；在线沿用现有边缘漏金属检测，参数统一保存后生效，边缘破损仅参与页面分项试检。不因分时频闪设置切换为涂胶沾料算法，多重曝光相关的其他精度换算、喷码规则及光源控制仍按项目配置生效。

旧碳膜漏箔专属区域和参数不再使用，旧区域不会转换为边缘区域，也不会把旧参数复制到边缘参数。原来只配置了碳膜漏箔区域的料号，需要重新设置边缘区域并完成试检、保存；已有边缘区域和参数保持原配置。

“本项试检”仅运行当前项目，“整图检测”验证完整的检测与分类流程。结果区显示检测中、已完成、失败或未完成；未完成与失败不能作为OK依据。修改参数后提示重新检测，仍需人工重新执行试检。

单击检出结果添加定位框，双击放大到该范围，双击主图恢复视图。定位框不替代原有红绿判定和预检测轮廓。选中项下方显示类别、区域和测量值；“过滤/保留说明”显示完整来源与原因，绿色记录表示过滤或忽略，红色记录表示保留缺陷。说明记录不计入正式缺陷表。

特定瑕疵预检测

进入“涂膜检测 → 特定瑕疵预检测”。此功能替代原削薄检测，直接使用当前相机已添加并启用的碳膜区域。先配置碳膜区域及定位，再分别勾选“启用亮瑕疵检测”“启用暗瑕疵检测”，设置对应的面积范围（mm²）、纵向最小长度（mm）、灰度范围和缺陷名称。两类开关默认均关闭，默认名称分别为“亮瑕疵”“暗瑕疵”。

参数独立于“区域亮暗瑕疵检测”和历史削薄参数，历史值不自动复制。“最大检出个数”为1～100的整数，默认2；每个碳膜区域的亮、暗缺陷分别计数，按连通域实际面积从大到小保留前N个，面积相同时保持原顺序。面积和最小长度条件同时满足才保留候选。

亮、暗瑕疵的红色标注沿实际检出区域的边界绘制，包含孔洞边界。分项试检、整图试检、在线显示、点检及启用的NG标注预览使用相同轮廓；缩放和平移后仍与图像位置对应。碳膜检测区域的定位框继续按原设置显示。结果表的面积、长宽、起止坐标仍沿用原测量口径，起止行列表示外接范围；原图和瑕疵小图的裁剪、像素内容保持原样。轮廓显示异常会记录原因，不改变检测结论，也不触发该区域重新检测。

点击本页“本项试检”只试检预检测，使用当前相机尚未保存的参数与定位区域草稿，无需标准模板或碳膜AI模型。参数自动换行并完整展开；统一保存后，在线和点检使用正式配置。此功能适用于现有HALCON碳膜检测体系。

在线、整图试检和点检先对各碳膜区域执行已启用的预检测。两类都开启时，两类均检测完成；某个区域任一类检出合格缺陷，该区域就跳过后续传统或AI碳膜瑕疵检测，其他通过预检测的区域继续按原流程检测。跳过状态仅用于当前帧，不改变区域启用设置。全部区域均被预检测判为NG时，直接使用预检测结果；仍有区域需要碳膜检测时，继续执行原标准模板和模型检查。

预检测检查定位后的完整碳膜区域，碳膜专有的边缘灰度、类别屏蔽继续作用于后续碳膜算法。预检测结果沿用现有尺寸修正、二次分类、图像、统计和输出流程；二次分类改名不会触发该区域补跑碳膜检测。参数无效或预检测异常时记录原因，未成功完成预检测的区域仍执行原碳膜流程。

旧削薄区域及参数保留历史数据，但停止参与检测，旧区域不会转换为碳膜区域。需要预检测时，请在碳膜检测入口添加并启用碳膜区域，再配置并保存本页参数。两个预检测开关均关闭时，碳膜检测沿用原流程。

保存时的缺陷名称校验

保存时仍按原规则检查各类缺陷名称。名称为空、只有空白或包含非法字符时，提示会列出相机、页面路径、字段和原因。关闭提示后，可见页面会自动定位到对应输入框。

名称所在入口被隐藏、已移除或属于另一算法模式时，会打开“修正缺陷名称”窗口。历史涂胶沾料名称仍保留原校验规则。输入有效名称并确认后，只更新当前草稿，需要重新点击保存；非法输入可以继续修正。取消或关闭窗口保留原名称。修正期间权限、登录会话、料号或相机发生变化时停止写回，重新核对当前编辑对象后保存。

工艺专用检测

界面按工艺提供区域亮暗瑕疵检测、虚边、特定瑕疵预检测、间涂拼图或屏蔽间隙等选项。仅配置当前工艺实际使用的功能，先核对区域、图像尺寸和配套模型，再逐项试检。

间隔涂布的两种进图方式均在“瑕疵工具 → 其他检测配置 → 间涂配置”中设置。完整操作、参数含义和无法拼图的判断见间隔涂布：拼图与间隙过滤；过滤命中会跳过当前整帧的尺寸与瑕疵检测。

检测区域无效、越界或定位失败时，优先处理区域与图像条件，不先通过放宽面积或灰度阈值掩盖问题。

调整参数时怎样比较

项目主要影响核对方法
检测区域与内缩决定实际参与检测的范围；内缩过多可能漏掉边缘缺陷。同时查看区域边界和已知缺陷位置，先解决定位与越界。
亮暗阈值差改变与背景差异的检出条件，过宽松可能增加正常纹理误报。正常图和缺陷图成组比较，不仅检查一张缺陷图。
最小面积及噪点过滤抑制小区域，也可能去掉真实小缺陷。记录目标缺陷的测量面积，核对 px 与 mm²，逐步调整。
模板、AI 与分类分别影响参考背景、模型识别和最终类别。保留原图与整图检测结果，区分未检出、被过滤和被改名。

误报、漏检与结果不一致

  1. 确认当前相机、料号、原图与启用区域，检查缺陷是否确实位于有效区域内。
  2. 检查定位是否成功。即使画面沿用旧区域，也不能认为本帧定位正常。
  3. 用标准图核对注册，再用缺陷原图做整图检测，观察候选的位置和大小。
  4. 有候选但最终结果没有时，查长宽面积筛选、边缘／底涂过滤；有结果但名称不同则查模型标签和二次分类。
  5. 保存后再确认正式配置，记录修改前后参数和同一组图像的结果。

正常图通过与缺陷图检出都需要确认。只降低阈值让某张图检出，可能同时增加其他图像的误报。小图分类结果不代表整图业务结果，参见筛选与分类顺序。
